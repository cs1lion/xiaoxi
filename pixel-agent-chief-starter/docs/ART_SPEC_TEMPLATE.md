# ART_SPEC.md — 像素世界视觉规范 V1（模板）

> 由 Pixel Art Director 根据当前真实画面和资源制定；未经截图/实际运行验证的内容先标“提案”。

## 1. 画面与像素规则

- 投影：纯 2D 正交、俯视/斜俯视的实际实现以项目现状为准。
- 缩放：关闭抗锯齿模糊，优先整数缩放与像素对齐。
- 基准 Tile/角色尺寸：待通过当前样品确认；设计文档列出过 16px Tile 与 32px Tile 的不同建议，不可未验证就硬编码成最终规范。
- 原生分辨率：待确认。

## 2. 颜色与材质

- 建立语义化调色板：轮廓、暗部、基色、亮部、强调色、UI 文本、世界焦点。
- 每种主要材质定义 3–4 级色阶；木、石、金属、水、草地使用不同像素簇方向。
- 限制高亮/强调色的使用，让角色、路径、工坊状态与交互点优先可读。

## 3. 形状与环境细节

- 角色与建筑先做剪影辨识；建筑按地基/主体/屋顶/前景拆层。
- 植物采用少量有层次的形态变体，避免随机散点填充。
- 环境动效低频、低对比、有相位差；特效不能淹没角色轮廓。
- 首轮只做垂直切片：地面 + 1 建筑 + 1 角色 + 1 植物 + 1 道具 + 1 个代表性光源/天气效果。

## 4. 像素与构图验收

- 原生分辨率下，3 秒内能指出主角、主要路径/交互点和当前神谕状态。
- 400% 放大检查地面接缝、像素簇、边缘与遮挡层是否连续。
- 白天/雨天场景比较可读性；暗化效果不得抹掉角色关键轮廓。
- 提交参考截图、实际运行截图与明确的差异说明。
