# DEMO_SCRIPT.md — MVP 1.0 三分钟演示剧本（待补完/批准）

> 按设计文档要求，先写并批准演示剧本，再开展扩展施工。下表是供团队细化的模板，不代表所有产品细节都已定案。

| 时间 | 用户看到什么 | 用户输入/事件 | 世界反应 | 验收证据 |
|---|---|---|---|---|
| 0–15s | 预置像素小镇、祭坛、工坊、小人 | 首次打开 | 小人有低频日常活动；界面引导如何输入第一条神谕 | 截图/录屏 |
| 15–60s | 研究工坊及待命角色 | 输入“帮我查个资料”（Mock） | 祭坛反馈；角色响应、行礼、寻路、进入工坊；工坊显示 Operating/进度 | 事件流+录屏 |
| 60–90s | 工作中的工坊 | Mock 任务完成 | 角色交付；显示模板式日报 | 报告内容+状态快照 |
| 90–125s | 晴天地图 | 输入“下雨” | 雨效出现，户外小人按规则避雨，TTL 后恢复 | 状态断言+录屏 |
| 125–155s | 当前世界状态 | 关闭/重开或触发保存/加载 | 网格、编年史与资源恢复 | 保存文件/加载测试 |
| 155–180s | 可用的调试界面 | 查看实体与事件流 | 能定位任务状态和失败原因；LLM 离线时仍可运行 Mock | 测试报告 |

## 需在剧本批准前明确

- 初始地图与窗口尺寸、原生像素分辨率。
- UI 的具体位置和首次打开引导。
- 每个演示阶段的预期状态与可观察的事件。
- 关闭重开是否由自动存档触发，存档频率和失败提示。
- 不纳入 MVP 1.0 的内容：语音输入、TTS/语音陪伴、多轮对话、自由生成、完整 Light2D 等。
