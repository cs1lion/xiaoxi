1项目是什么

阿栖：一个有性格、有记忆的中文语音聊天角色。README 开宗明义——不是"做一个有记忆的 agent"，而是做一个能在长期互动里保持角色一致、理解共同经历、并以合适方式参与对话的角色系统。代码按五层契约组织：角色契约 → 记忆契约 → 节奏契约 → 语音 → 验收场景。

三条用户路径：一起聊（角色连续性）/ 一起做（任务执行与回执）/ 一起学（字幕片段解释与练习）。技术栈：FastAPI + SQLite + 原生 JS 前端 + faster-whisper/edge-tts/StepAudio 语音 + SVG/VRM 形象。当前为单用户、本机、单进程定位。

4质量信号（这个项目真正值钱的地方）

  • 文档诚实度罕见：每份文档严格区分「设计 / 源码 / 离线验证 / 真实验收」四种状态；明确写下"接口返回 200 只说明入口可访问，不证明最新源码已部署"、"fake 模型通过不等于真实模型不谎报"、"原话存在不等于候选含义正确"。这种自我约束比代码更难写。
  • 测试是真测试：用真实 ASGI 应用装配、临时数据库、只读 SQLite 逻辑指纹验证真实库不被污染；发现过"以为隔离了实际没隔离"的测试事故并如实记录（含记忆库被清空、无备份、不声称恢复）。
  • 契约驱动：性格/记忆/节奏三份 YAML 即产品规格；把"协议约定变成机器可检"（check_protocol.py），并真的抓住过一次协议漂移。
  • 记忆证据链是深度工程：原消息 ID → 候选引用 → 身份 (kind, subject, key) → 写入决策 → 晚到守卫 → 删除代代际。这正是 AI Agent 岗（长期记忆 / Tool Use）面试最硬的素材。
