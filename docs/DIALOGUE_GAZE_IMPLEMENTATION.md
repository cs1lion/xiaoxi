# 交流眼神：第一轮实现与验收

日期：2026-10-14（Asia/Shanghai）。本轮在已有眉高、下睑、笑眼、眨眼与口型之上增加对话时序，让眼神跟随倾听、思考、真实发声与打断。

后续[交流眼神 V2](DIALOGUE_GAZE_V2_RESULTS.md)已增加三档风格、错开的眉眼回应和有限可复现的移视计划。本文保留第一轮数值与历史证据；当前行为以 V2 为准。

## 体验

- [交流眼神实验室](http://127.0.0.1:8000/static/avatar_lab.html?model=daily-lids&dialogue=1#dialoguePanel)：选择正常回应、回复较慢或中途打断，再点“播放眼神流程”。演示为静音口型，使用真实浏览器音频时钟。
- [真实聊天入口](http://127.0.0.1:8000/?avatar=seed-daily-lids)：使用现有聊天与语音播放；关闭鼠标跟随后使用交流眼神。

动态体验应使用普通播放入口。`calibration=1` 会固定画面，适合检查形变；无法用冻结场景判断连续动作。

## 来源与实现计划

参考 [Furhat 与 Asap 官方源码研究](DIALOGUE_GAZE_RESEARCH.md)，采用三个机制：关注当前说话者；思考移视是会返回的临时动作；打断撤销旧计划并进入回看。Furhat 的用户目标微运动示例支持“在关注目标附近保留小幅变化”，这里的微眼跳由本项目已有 IdleDriver 实现。

本轮按以下顺序落地：

1. 把目标时序独立成导演，复用已有眼头协调、微眼跳与眨眼。
2. 接入录音、思考与实际播放器边界，区分生成文字和播放声音。
3. 处理分句空隙、迟到音频、打断、临时降音量、错误与手动控制。
4. 加入三种可重复演示，检查真实模型、校准恢复与移动布局。
5. 用连续播放画面复查观感，保留来源、源码哈希和本轮证据。

官方源码的具体时长不直接套用到当前角色。本轮数值是可调整的起点，不是经过用户研究确认的最佳值。

## 已实现的行为

| 状态或事件 | 眼神与已有表情如何配合 |
| --- | --- |
| 倾听 / 持续监听 | 以镜头方向为关注目标，保留低幅、低频微眼动；已有倾听姿势与眉毛继续工作。 |
| 思考 / 准备回应 | 等待约 0.35 秒后临时移视 0.8 秒，再回看。等待持续较久时最多按 8 秒周期再次移视。 |
| 文字、情绪或生成完成先到 | 可以退出旧思考手势，继续等待音频；这些事件本身不会进入发声状态。 |
| 实际音频起播 | 跟随 AudioContext 时钟到达起播点进入回应，恢复用户目标，口型与已有表情继续合成。 |
| 分句间隙 | 当前轮未结束时保持关注；已经发声后不在句间重新触发思考移视。 |
| 生成完成 / 文字回复 | 聊天层等队列真正空闲后结束话轮。纯文字回复无需伪造发声。 |
| 用户打断 / 停止播放 | 撤销所有已登记及尚未开始的眼神片段，清理旧口型和手势，再跟随当前状态。 |
| 暂时降音量 | 让出关注，但保留实际音频片段；声音恢复时可回到回应。正式打断才取消片段。 |
| 手动注视 / 眉眼预览 / 明确的表情眼位 | 暂让对应控制拥有视线；后台时序继续推进，归还时只采用当前目标。 |
| 非致命播放或配置提示 | 依据真实录音、播放和队列状态保留眼神；致命错误、断开与取消会退出。 |

“用户方向”是镜头方向的约定，没有测量用户位置或接入人脸追踪。

## 接线与通道所有权

`DialogueGazeDirector` 只输出目标坐标与微眼动上下文，绝不直接写眼皮、笑眼、眨眼、嘴型或头部形变。

| 文件 | 本轮职责 |
| --- | --- |
| [dialogue-gaze.js](../web/avatar/drivers/dialogue-gaze.js) | 状态、临时移视、音频片段门控、取消与所有权恢复。 |
| [idle.js](../web/avatar/drivers/idle.js) | 保留已有眼头运动，用上下文缩小微眼动与拉长间隔；释放时恢复原配置。 |
| [index.js](../web/avatar/index.js) | 在采样前判断实际眼位所有权；只含头/眉的手势不冻结微眼动；明确眼位用现有 mute 排除低层叠加。 |
| [app.js](../web/app.js) | 从已有状态 UI 与实际 PlaybackQueue 接入；分句空隙保留当前轮；继续使用现有 TurnGate 拦截过期事件。 |
| [calibration.js](../web/avatar/calibration.js) | 快照与恢复导演、上下文和帧状态。实验室进入校准前先停止演示。 |
| [avatar_lab.js](../web/avatar_lab.js)、[avatar_lab.html](../web/avatar_lab.html) | 三种静音演示、交流眼神开关与自然模式；停止使尚在等待音频恢复的启动失效。 |

默认思考手势原有的头和眉保留，旧 EyeBall 轨道由交流计划接管。其它显式眼位手势及情绪，包括明确的零值，继续拥有自己的眼位。眨眼仍在最后与眼开度相乘，闭眼帧为零；语音继续拥有开口通道。

没有服务器协议或模型资产变更；旧模型复用基本注视与眨眼。L/R 仍沿用角色侧的现有参数约定。

## 当前试调值

可通过 `config/avatar.yaml` 的 `gaze.dialogue` 提供同名选项；未提供时使用导演默认值，输入会限制在合法范围。

| 选项 | 默认值 | 含义 |
| --- | --- | --- |
| `thinkingDelay` | 0.35 秒 | 首次移视前等待。 |
| `aversionDuration` | 0.8 秒 | 单次移视目标保持时间。 |
| `repeatInterval` | 8 秒 | 持续等待的稀疏重复周期。 |
| `aversionX` / `aversionY` | 0.30 / −0.16 | 现有归一化目标空间的偏移，非角度或直接形变权重。 |
| `listenDrift` / `waitingDrift` / `speakingDrift` | 0.035 / 0.045 / 0.07 | 对已有微眼动的幅度上下文。 |
| `listeningIntervalScale` / `speakingIntervalScale` | 1.8 / 1.15 | 对已有微眼跳间隔的倍率。 |
| `reducedMotionScale` | 0.45 | 减少动态时的位移与微眼动倍率。 |

目标通过既有 IdleDriver 和参数平滑逐步到达，0.8 秒表示目标保持段，不是测得的眼球运动时间。

[56 项浏览器证据](../eval/avatar/dialogue-gaze/2026-10-13T23-48-46-822Z/results.json)覆盖未来音频、重复状态、分句、手动/表情所有权、下睑与闭眼口型、完整校准字段恢复、旧模型、减少动态、移动布局、等待音频恢复时停止，以及真实聊天延迟解码、过期轮、实际播放、非致命错误和打断。聊天测试保留生产 Avatar、VRM 与 PlaybackQueue，只替换网络、麦克风和音频设备接口；没有实测外部 TTS 或真实用户语音。

[既有浏览器回归记录](../eval/avatar/dialogue-gaze-regressions/2026-10-13T23-51-28-030Z/results.json)保存每套的原源码哈希、执行副本哈希、日志与独立输出。副本仅修改证据输出目录，按顺序运行，未覆盖历史校准结果。

连续视觉验证分两次：

- [22 张实际播放截图与状态轨迹](../eval/avatar/dialogue-gaze-preview/2026-10-13T23-50-05-425Z/results.json)，普通 RAF 与 AudioContext 持续运行；选出截图前后状态相位一致的六帧组成[对照图](../eval/avatar/dialogue-gaze-preview/2026-10-13T23-50-05-425Z/contact-sheet.png)。一次临近打断边界的截图前后状态不同，未用于标注同一相位。
- [独立连续录制](../eval/avatar/dialogue-gaze-preview/2026-10-13T23-54-05-533Z/continuous.webm)及[来源与状态观察](../eval/avatar/dialogue-gaze-preview/2026-10-13T23-54-05-533Z/results.json)。这次没有并行截图，避免截图过程影响录制画面；复查了[视频 3–6 秒](../eval/avatar/dialogue-gaze-preview/2026-10-13T23-54-05-533Z/video-thinking-strip.png)与[31–33 秒](../eval/avatar/dialogue-gaze-preview/2026-10-13T23-54-05-533Z/video-interrupt-strip.png)的连续帧。

两次采集均为 Windows 无头 Chromium，浏览器报告 AMD Radeon 780M / D3D11。每次保存本轮运行文件快照、哈希和模型哈希，页面异常为 0。这里没有测量 FPS、CPU/GPU 延迟或性能收益。

人工复查可见轻微眼头配合、临时移视后的回看，以及打断后口型收回和恢复倾听；连续录制未见瞬间跳到旧移视目标。全闭眼帧没有明显虹膜漏出。移视幅度偏克制，是否符合角色个性仍应通过实际聊天和用户判断继续调整。

## 限制与下一步

本轮完成发声边界时序，没有依据逗号、句号猜测语音停顿。后续若取得可信静音段或音素时间，可参考 Furhat 的停顿移视，再做针对当前角色的连续试听。

眉高、下睑与笑眼仍使用已有 V3 资产，下睑保持近似能力说明；未新增独立上睑、眉角、眉曲率或瞳孔通道。没有比较实验来证明自然度提升，也没有把此前 V3 的 82 张图、76 项像素合同或约 60 FPS 当成本轮时序或性能证据。

正式官方文档的获取限制、固定提交源码与论文未读全文的边界保留在研究文档中。下一轮优先在真实对话中调整移视频率和眼头幅度，再为不同情绪设计进入、停留与退出节奏。
