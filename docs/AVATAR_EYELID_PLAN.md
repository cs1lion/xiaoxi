# 独立下睑与左右笑眼实现计划

日期：2026-10-13。承接[第二轮眉眼校准](AVATAR_CALIBRATION_V2_RESULTS.md)，用户确认下一轮优先研究并实现独立下睑与左右笑眼。

## 目标与保护项

开心增加下睑参与，减少依赖整只眼睛闭合；害羞保留轻微左右差异与移视；困困继续维持半睁眼，并在完整眨眼后恢复。表情、注视、独立眉高和语音口型继续合成。

使用独立候选 `seed-daily-lids.vrm`，来源为已验证的 `seed-daily-eyes.vrm`。保护中性几何、已有所有 morph 与权重、材质贴图、拓扑、rig/skin、标准 blink、LookAt、元音及许可元数据。原 Daily 与上一版独立抬眉资产继续可选，不修改其构建器或验证规则。

## 执行顺序

| 阶段 | 交付 | 验收依据 |
| --- | --- | --- |
| 1. 真实几何分析 | 原 smile/close 顶点支持、眼区连通组件、重复位置与上下局部贡献 | 排除嘴部、中线、眉毛及隐藏特效；记录选择规则与几何局限 |
| 2. 候选资产 | 左右眼区 smile、左右局部 lower lift 四个零默认权重目标 | 独立验证保护全部旧资产；跨侧、接缝、旧绑定与许可篡改测试 |
| 3. 运行接线 | 独立参数、native/calibrated 模式、候选专属预设、普通聊天笑眼合成 | 原模型保持原路由；逐侧眨眼退权；完整闭合与恢复；退出还原 |
| 4. 固定场景 | 开心/困困/害羞原生基线与候选，单侧下睑/笑眼，四向视线与口型压力集 | 冻结相机、光照、头姿、视口及模型；不重新配准；独立 head 锚点不漂移 |
| 5. 像素证据 | 上睫毛外缘、可见眼区下缘分别测量，保存完整列/固定中央带曲线与原始 mask | 下缘确实上移、上缘稳定；对侧与眉区保持；分割无效时明确拒绝结论 |
| 6. 正常播放与交付 | 实际渲染 CPU/GPU 样本、实验室/聊天入口、报告与可复现命令 | 原始样本可重算；环境与范围明确；保留人工神态判断 |

## 通道定义

`neuro_eye_smile_L/R` 拆分原始 smile 的眼区贡献，同时剔除嘴部位移。`neuro_lower_lid_raise_L/R` 从真实眼区的原闭眼正向 Y 贡献中连续提取，最大幅度为原贡献的 0.30 倍；不把它称作纯垂直位移，也不宣称完成独立上睑重制。真正的下睑语义必须经上、下边缘截图测量确认。

参数为 `ParamEyeLLower/RLower`（0–1，中位 0），左右笑眼继续使用 `ParamEyeLSmile/RSmile`。参数与 morph L/R 沿用角色侧；手动 UI 与 ROI 使用画面侧。正面画面左眼对应参数 R。

新目标逐侧乘最终眼开度，眨眼闭合时退让；全闭帧只由既有标准 blink 输出。完整通道集合才启用 `seed-lids` 适配，不以半套通道宣称独立下睑可用。旧模型不近似消费新 lower 参数。

固定场景的原生模式复现上一版预设，候选模式采用新预设。生产聊天为新模型的“调侃”“得意”补充轻量全眼 smile 与 lower 默认值，在既有情绪过渡和强度缩放之前参与混合。任一侧显式配置 smile 或 lower（包括 0）时，该侧保留配置；其它驱动已提交的意图不再整体二次改写。候选专属预览随后覆盖对应通道，释放预览后归还聊天驱动。此轮不更改虹膜质感、身份或配色。

六阶段技术交付已完成，详见[第三轮结果](AVATAR_CALIBRATION_V3_RESULTS.md)。正式运行保存 82 张截图，456 项结构检查与 76 项像素合同通过；固定中央带下缘在半/满强度中位上移 3/7 px，上睫毛外缘保持。实际播放三个 10 秒场景约 60 FPS，原始 CPU/GPU 样本已保存。技术通过与艺术确认分开，艺术确认仍为 pending。
