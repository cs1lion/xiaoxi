# 个人笔记：明确保存 → 检索 → 用户确认行动

入口：主页侧栏「个人笔记」，或 /static/notes.html。

2026-10-13 更新：已加入不可覆盖的保存版本、明确笔记关联与跨连接活动恢复。打开/保存不会自动关联；选定 v1 后保存 v2 仍固定 v1，并提示新版。历史版只读，删除会同时删除所有版本和自身关联。自动正文读取与只读模型工具已接入，范围及验证见 [SHARED_ACTIVITY_CONTINUATION.md](SHARED_ACTIVITY_CONTINUATION.md)。下文保留最初手动任务入口的说明。

已实现独立 SQLite notes.db：标题、正文、用户提供的来源说明、版本与时间；字面关键词查询（中文可用，最多50条），编辑及删除带版本校验。来源字段是说明，不是经过验证的引用证据。无自动聊天采集、文件扫描、向量服务或模型调用。

用户可载入笔记、准备任务草稿、修改标题并明确确认；未点击确认不创建任务。任务只携带笔记ID和版本，不复制正文。删除笔记不删除此前已确认任务，界面明确提示。检索不到笔记不代表资料从所有备份中抹除；SQLite逻辑删除不是安全擦除，也不追溯清理已有备份。

本版手动从笔记标题准备任务草稿；模型可以只读固定保存版，但自动提取行动项并保存修改建议尚未实现。笔记版本在创建任务前再次核对；跨接口核对和建任务不是单一事务，仍有极短并发窗口，来源指向已读版本而不是保证最新版本。

验证：scripts/test_notes.py 四项存储/接口测试；scripts/test-notes-browser.mjs 八项真实浏览器→TestClient传输桥→真实路由→临时SQLite检查通过，包括保存、中文检索、确认前不建任务、任务来源、冲突保留、删除与任务独立。无生产数据写入。

部署：本批新增后端路由需要更新运行进程后才可使用。未再次重启现有服务；静态页面可以加载但旧进程可能返回404。使用已确认的备份与重启程序后再进行生产只读验收。
