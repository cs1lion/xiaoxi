# 事实记忆证据链第一步

日期：2026-10-13。本文主体记录项目路线 A 阶段的事实记忆基础及当时的离线验收；该阶段未调用真实模型、读取真实用户数据库或重启生产服务。后续授权的真实模型首轮结果见文末链接，历史证据保留。

## 使用与结果

普通文字和语音对话的用户消息现在在首次模型等待前保存，取得整数消息 ID。后台抽取只收到这条已保存用户消息；助手回复、没有 ID 的自由文本和旧会话上下文不能替代证据。体验、练习及剧场路径仍保持原有隔离。

记忆面板区分“有原话证据”“手动保存”和“旧记忆，未关联原话”。关联记录可展开“查看原话”。勾选“显示历史和待核对记录”可查看历史版本及冲突候选；冲突标为“待核对，不自动使用”，可修改或忘掉。默认只列当前记忆。

例如“我在甲公司工作，岗位是设计师”，公司和岗位分别保存为 `工作:公司`、`工作:岗位`。随后说“我在乙公司工作”而无法确认是在纠正同一属性时，新说法成为冲突，原记录仍有效；明确的变化原话和 `update` 候选一起满足门限后，才将旧版本转为历史。用户在记忆面板的修改是独立的明确入口。

## 已实现的契约

| 环节 | 实际行为 |
| --- | --- |
| 证据 | 验证消息存在、角色为 user、同一会话、与当轮输入相符；引用须是该条原文的非空连续子串，最多 1200 字 |
| 候选 | 类型、主体、来源和操作有效；数字有限；自动主体只允许 user，类型为 fact/episode/todo，用户原话不自动转成角色 self_state；缺少 source 不再默认明确陈述 |
| 身份 | `(kind, subject, key)` 为当前事实身份；主题只分类，同主题独立属性不互相覆盖 |
| 写入 | ADD / NOOP / UPDATE / CONFLICT；模型提供的 status、supersedes、decision 和证据状态不构成写入权限 |
| 来源 | inferred / uncertain 不使 stated 失效；弱来源重复不替换强证据；同值来源升格同步证据所属会话和来源分值 |
| 冲突 | 默认列表、检索和提示不自动使用 conflict；查询已完成事项时也不会混入 conflict |
| 顺序 | 以原始消息 ID 排序；首次证据与最新同等或更强来源确认分开保存，晚到抽取不能压过较新的确认或纠正 |
| 关闭与人工维护 | 关开记忆、人工添加/纠正及删除使已接受的旧任务失效；写事务再次验证持久 epoch |
| 删除 | 按记忆 ID 默认删除相同身份的完整历史；按 key 显式删除全部匹配记录，不再限于最近 1000 条 |
| 重启保护 | 持久 write_floor 禁止重新自动抽取维护操作前的旧消息；重启和另一数据库连接也受此约束 |

当前水位是保守的**全局**水位：维护一条记忆时，其他已接受但尚未写入的旧抽取也可能被放弃；维护后新收到的消息仍可正常记录。推测预算按会话的实际保存记录计算，包含历史和冲突；这是当前单进程应用的配额，尚非跨工作进程的硬配额。

忘掉记忆删除的是记忆及其版本链，**不会删除原始聊天日志**。旧日志不会因此被后台重新抽取成记忆；同会话的近期聊天仍可能出现在对话上下文中。清理原始聊天属于另一项数据管理能力，不能把本轮功能理解为抹除所有对话资料。

## 数据兼容

SQLite schema 从 v1 增量迁移到 v2，保留记忆、消息、会话、历史 ID、时间及使用计数；移除旧的仅按 key 唯一索引。旧记录标为 `legacy`，不猜测或补造消息引用；人工保存标为 `manual`，新自动记录为 `linked`。同值 NOOP 通常保留首次证据和原时间；较新确认仅推进排序字段，来源增强时才使用新的有效证据。

新增可返回字段：`evidence_message_id`、`evidence_quote`、`evidence_state`、`decision`、`last_observed_message_id`。NOOP 的 decision 反映最近一次处理，不是一份独立、不可变的完整决策日志。数据库比支持版本新时明确拒绝打开；迁移失败回滚，不要求删除库。迁移验证全部在临时合成副本上进行，真实用户库尚未迁移。

## 验证及限制

新契约测试共 **103 项**：抽取 25、存储与迁移 34、证据生命周期 33、真实导入的编排接缝 4、真实应用 ASGI 接口 7。编排接缝覆盖原话保存→模拟抽取→实际持久化→新会话检索，以及流式/同步生成途中删除、回复倒序完成。接口测试真实装配应用及助手模块，但数据路径限定为内存或临时目录；没有运行调度器或监听服务。模型和音频供应方是离线替身，不能据此推算真实抽取准确率、回答质量或听感。

其他回归：记忆检索 13、核心 38、回复接缝 4、语音流交付 20、语音 WebSocket 30、体验会话 19、体验 WebSocket 20、练习 WebSocket 18；协议检查通过。记忆面板及主语音页面真实 DOM 的离线浏览器验证 **27 组通过**，包括原话逐字保留、安全展示、来源标签、历史/冲突和编辑/忘记刷新。

证据链阶段的 [契约探针记录](../eval/research/memory_contract_probe_evidence_20261013.json) 是 **6 项满足、2 项缺口**，旧 [基线记录](../eval/research/memory_contract_probe_20261013.json) 保留不变。后续已修复“详细解释并举例”当前覆盖与省略语言名的文件脚本场景；[策略后续报告](../eval/research/memory_contract_probe_strategy_20261013.json) 为 **8 项满足**。这些仍是人工候选的程序规则探针，不能替代模型评测。

**原话存在不等于候选含义正确。** 引用、第三人、假设和扮演的过滤，以及变化表达的检测，仍是有限、保守的词法门限。它们可能漏收真实自述，也可能漏掉未覆盖的第三人表达；模型仍可能误写属性、来源或总结。来源分值是排序约定，不是测得的正确率。尚未完成语义蕴含验证、事实有效时间、属性同义消歧、完整 60 例题族或真实模型对照评测。
