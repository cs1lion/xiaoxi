## 一句话结论

画面「一片同亮度」的根因不是细节不够，而是**16 色里有 6 个色挤在同一条亮度带上**。**只调 1 个色值（`stone`）就能把核心指标从 68.29% 压到 48.07%，成本极低、风险可控。** 建议批准方案 A。

## 2. 重排方案（三选一，均**不加色、不改色相、不动 `amber`**）

所有方案的实现手法相同：**只对现有色值做等比明度缩放**（保 HSV 色相与饱和度比例），不引入任何新色。

### 方案 A｜只推 `stone` 一个色（**推荐**）

| 项 | 值 |
|---|---|
| 改动 | `stone` `#3a3f3b` → **`#3e433f`** |
| 明度 | 61.65 → **66.00**（+4.35） |
| 色相变化 | **0°**（等比缩放，色相/饱和度不变） |
| **众数带 48–63 占比** | **68.29% → 48.07%（−20.22pp）** |
| IQR | 9.39 → **13.39** |
| 标准差 | 22.30 → 22.54 |
| 明度均值 | 56.92 → 57.75 |

**原理**：`stone` 占屏 20.22%，且明度 61.65 只差 2.35 就跨出带边界 64。把它推过 64，**20.22% 的像素整块搬出拥挤带**——一步完成一半目标。

**视觉效果**：石路/广场明显亮于草地，路面从「和草地同色的灰块」变成「清晰的铺装地面」。预览：`eval/screens/palette-preview-A____stone___64.png`

### 方案 B｜推 `stone` + 压 `grass`（更彻底，但有代价）

`stone` → `#404541`（luma 68）、`grass` → `#263227`（luma 47）。众数带 **39.82%**，IQR **20.99**。

**代价**：`grass` 压到 47 后，明度低于 `farm` 52.26，**打破地形高度序 `grass > farm`**（约束检查 `orderOK: false`）。会让草地在农田旁边读起来更暗，语义反了。**不推荐。**

### 方案 C｜四基色均摊（最彻底，改动最大）

`grass`→46、`farm`→40、`stone`→68、`plaza`→84。众数带 **46.95%**，IQR **27.52**（最高）。

**代价**：改 4 个色值，`farm` 明度降 12.26、`grass` 降 9.08——画面整体变暗变冷，风格偏移最明显。虽然约束检查全过（`orderOK: true`），但**视觉变化幅度已超出「微调」，接近换风格**，用户需明确知情。

### 方案对比

| | 改几个色 | 众数带 | IQR | 是否达标(<60%) | 高度序 | 视觉变化 |
|---|---|---:|---:|---|---|---|
| 现状 | — | 68.29% | 9.39 | ✗ | ✓ | — |
| **A** | **1** | **48.07%** | 13.39 | **✓** | ✓ | **轻微** |
| B | 2 | 39.82% | 20.99 | ✓ | **✗ 破序** | 中等 |
| C | 4 | 46.95% | 27.52 | ✓ | ✓ | 明显 |

## 5. 给非美术读者的画面预期

**改之前**：石路和草地是几乎同一种灰绿，整幅画看起来像「一块调子略平的灰绿色地毯，上面摆几个房子」。

**改之后（方案 A）**：石路明显亮起来，**路是路、草是草**，视线会自然沿着亮的路面走。整体仍是原来的暗绿夜色调，风格不变，只是层次拉开。

## 6. 建议

**批准方案 A，作为独立小改动实施**（改 1 个 hex + 同步 2 处门禁 + 重测像素基线）。

理由：
1. **性价比最高**：改 1 个色值达成核心指标 −20.22pp，超过 60% 阈值要求；方案 C 改 4 个色只多 1.12pp。
2. **风险最低**：不破地形高度序、不破可读性、色相零变化，视觉上是「同一套配色拉开层次」而非「换风格」。
3. **可验证**：实施后按 §8.1b 同一脚本（`round-08.mjs` 同口径）重测，众数带应落到 48% 附近，若实测偏差 >5pp 说明模型有偏，可回滚。

若用户希望一次到位、接受明显风格变化，则选方案 C。**不建议方案 B**（破坏地形高度序）。

## 附：方法与可复现性

- 模拟模型：把每个像素按「最近源色」归属，再按 token 的明度缩放系数重算颜色，最后用同一套 `luma255` 公式重算统计。
- **模型校准误差 0.00pp**：不改任何颜色时，模型复现 `68.29% / IQR 9.39 / 均值 56.92`，与真实截图**逐位一致**，因此预测可信。
- 复现脚本：`ego-scripts/palette-luma-01.mjs`（现状）、`palette-luma-02.mjs`（方案模拟 + 预览图生成）。
- 预览图生成：按 token 缩放系数逐像素重上色后重新编码 PNG（近邻采样，无插值），因此是「改色后的真实观感近似」。
