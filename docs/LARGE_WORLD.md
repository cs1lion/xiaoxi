## 未做（下一片）

### 郊野探索点（已完成）

三栋郊野铺子已落地：爬虫矿洞（查资料）、文档磨坊（整理文稿）、齿轮塔（写代码）。
派活规则见 `src/world/venue.ts`：

- **台账的活只去镇内铺子**，镇内忙就排队，不会塞给郊野；
- **你派的神谕活优先去郊野**，郊野忙再退回镇内。

判定用 prefab id 而不是距离：镇内书斋实测落在离祭坛 23 格处，按距离会被误判成郊野。

### 迷雾

`fogOfWar` 字段没加进 `TileCell`。原因：迷雾一旦影响通行，存档里写在迷雾区的建筑
读档时会变成孤岛。正确的做法是迷雾只约束**新建造**，不约束通行——这一点还没实现。

### 视野裁剪

当前整张 80×60 的地形是一次画进一个 Graphics 对象的。Phaser 会整块提交，
镜头移动时并不省算力。地图再大（比如 160×120）就需要按视野分块渲染。

## 与方案不一致的地方

方案写的是 `TileSize = 32px`，未采纳。图块放大与世界扩大互相抵消：同样一块屏幕，
图块翻倍就只看得到一半地图内容，还要重画全部地形纹理。保持 16px、只加格子，
才拿得到「辽阔」的观感。

方案写的 `walkCost`（石板 0.4、森林 2.5）方向对，但数值按实测定：石板 0.8 时
绕上大路根本不划算（绕路 18.8 > 直穿 16），0.6 才开始出现「先上大路」，
取 0.5 避免为了上大路绕太远。

## 实现中抓到的六个真问题

每一条都是真机或测试先失败才暴露的：

1. 未覆盖格子的默认分区是 `street`，大世界 72% 变成石板路。默认改草地。
2. 雾与雨按画布尺寸建，大世界里只覆盖视野。改按世界尺寸。
3. 雾带按世界底边定位，永远落在视野外。改成跟着镜头走。
4. overlay 用 `worldView` 换算，而它由 `preRender` 更新、场景 `update` 先跑。
   改用 `scrollX/Y`。
5. overlay 的 `gameWidth` 传了显示像素（960）而非逻辑像素（480），2 倍显示下偏一半。
6. 0 毫秒的 `cam.pan` 不当帧生效。直接 `centerOn`。
