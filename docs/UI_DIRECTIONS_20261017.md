# 小溪界面方向探索（2026-10-17）

范围：只做设计探索与静态原型。未改生产文件，未接业务状态，未提交。
原型目录：`web/design-preview/live-20261017/`。
对比页：`web/design-preview/live-20261017/index.html`。

## 1. 结论

推荐 **方向 B · 星图手帐（Star-Map Almanac）**。

它把现有的“暖纸 + 苔绿”从默认米色底升级成一套可执行的编辑语言。字级差最大，阅读顺序最清楚，形象第一次真正进入构图，用户已经接受的温度也保留下来。

方向 A 的氛围最强，但离上一轮已经试过又撤回的深色舞台最近，必须先证明它能长期承载长对话。方向 C 的颜色性格最鲜明，但舞台和输入区都偏重，是三者里最难在密集状态下落地的方向。

三份原型都不是把现有页面换一组颜色。A 重做了骨架、字体与形象窗，B 重做了阅读结构与图版，C 重做了主视觉与控件语法。

## 3. 三个方向

### 方向 A · 夜航星图（Nocturne Atlas）

**北极星**：夜里的观察室。界面是暗的，只有她所在的那扇窗是亮的。

**调性**：安静 4/5，精致 4/5，疏 3/5，重 2/5，庄重 3/5。依据是夜间独处与语音优先的使用场合，画面要有大气压，但不能变成仪表盘。

**标杆与取舍**：品类是语音陪伴与个人对话工作台。真实对照是当前主工作台截图与 `web/design-preview/NOTES.md` 里上一轮的深色舞台。外部同类没有取到真实首屏，不冒充看过。保留侧栏、主对话、输入区、抽屉与设置这些用户已经熟悉的结构；换掉上一轮的“粒子 + 三栏 + 金色光晕”，改成窗框、月光、星座线与一扇贯通的观察窗。

**生成引擎**：夜晚的观察室，材质是玻璃、深色石墙与暖灯。光线决定边框、留白和人物位置。

**首屏骨架**：

```
[ 288 夜航日志 ][ 620 文案列 ][ 430 贯通观察窗 ]
```

文案列自上而下是共同事项横条、章节标记、两行大标题、正文、三条编号建议。观察窗从顶栏下方一直落到输入区上方，窗内是人物、月光、星座线与地面接触影。

**字体**：

- 展示：Noto Serif SC 300，78px，行高 1.12，字距 0.015em。
- 正文：Noto Sans SC 14.5px，行高 1.95。
- 元数据：Consolas 10px，字距 0.18em。
- 界面标签：Noto Sans SC 11.5 至 12px。

**色彩**：

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 夜色 | `#070C11` | 页面底 |
| 深青 | `#101E27` | 观察窗与浮层 |
| 星白 | `#DCE8E6` | 主文字 |
| 远雾 | `#83979C` | 次要文字 |
| 微光 | `#6F858B` | 元数据，对比度 5.05:1 |
| 灯金 | `#E7B469` | 唯一强调色，标题落点与当前状态 |
| 深海 | `#2E6F72` | 星座线与冷侧轮廓，不做按钮色 |

**主视觉**：人物站在观察窗里，面部约占 96px 宽。窗框、月光、地面影和暖侧光共同接住她。她不是贴在角落的图，而是画面里唯一的光源。

**控件语法**：4 至 8px 小圆角，1px 冷色发丝线，按钮以文字和细边框为主。输入区是一条横向玻璃条，模式控件收在它的上沿，不再出现两枚漂浮胶囊。

**结构性突破**：把“头像”从右下角贴纸改成贯通的观察窗。窗占右侧 37%，与左侧文案形成一明一暗的双主角。

**记忆点**：标题里的“这里”是整页唯一暖色落点，与窗内灯光同源。

**放弃什么**：渐变文字、紫色光晕、满屏粒子、圆角卡片列、独立悬浮的模式胶囊。

**风险**：暗色长文可读性要逐条验收；它离“AI 陪伴就是深色发光”的行业套路最近，必须靠窗与排版拉开，而不是靠颜色。

### 方向 B · 星图手帐（Star-Map Almanac）

**北极星**：一本被摊开的夜航手帐。她是一张被裱进手帐的深色图版。

**调性**：安静 4/5，精致 5/5，疏 4/5，重 3/5，庄重 4/5。依据是“被记住的小事”与长期阅读，纸张、编号、书口和印章比发光更像陪伴的存档。

**标杆与取舍**：品类同上。真实对照是当前主工作台的暖纸截图与上一轮的设计说明。外部同类没有取图。保留暖纸与侧栏，换掉圆角卡片、苔绿强调色和“角落小人”。借用手帐的语法而不是贴纸纹，包括书口、页码、图版号、纸片与印章。

**生成引擎**：一本编辑物，材质是纸、墨、朱砂与旧金。排版决定结构，纹理只做低强度纸感。

**首屏骨架**：

```
[ 300 索引侧栏 ][ 34 竖排书口 ][ 546 主栏 ][ 400 图版 ]
```

主栏是大标题、正文、叠放的纸片“共同事项”、一/二/三编号建议。图版是右侧深色内衬，外面有纸边、金线与朱砂印。

**字体**：

- 展示：Noto Serif SC 600，70px，行高 1.16，字距 0.015em。
- 正文：Noto Serif SC 15px，行高 1.95。
- 界面标签：Noto Sans SC 12px。
- 图版号与页码：Consolas 9 至 10px，字距 0.14 至 0.24em。

**色彩**：

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 暖纸 | `#F2EADA` | 页面底 |
| 纸背 | `#E9DEC9` | 侧栏与纸边 |
| 纸片 | `#FBF7EE` | 共同事项纸片与输入条 |
| 墨 | `#211C16` | 主文字，对比度 14.13:1 |
| 灰褐 | `#6D5F4A` | 次要文字，对比度 5.19:1 |
| 淡褐 | `#746650` | 元数据，对比度 4.64:1 |
| 朱砂 | `#A93A2A` | 唯一强调色，印章、当前状态、发送 |
| 旧金 | `#9B7A3E` | 细线与图版边框 |
| 旧金字 | `#7C5F2B` | 金色小字，对比度 4.98:1 |

**主视觉**：人物在深色图版里，图版外有纸边、金线与朱砂印。深色内衬把人物从暖纸里推出来，脸约占 80px 宽。图版像一张被收藏的印刷品，不是悬浮卡片。

**控件语法**：0 至 2px 圆角，1px 墨线与发丝线。按钮以文字、下划线和方章为主。输入区是一条纸片，麦克风是墨色方块，发送是朱砂方块。

**结构性突破**：把“形象舞台”改成“图版”，并把它放进编辑物的版心。侧栏从卡片堆变成带编号与书口的索引。

**记忆点**：纸片顶部的胶带、图版右下角的“栖”字朱砂印、标题“这里”的双线。

**放弃什么**：圆角卡片、玻璃胶囊、苔绿主按钮、把人物长期放在右下角。

**风险**：朱砂与旧金一旦用多就会滑向“国风模板”。彩色面积必须压在 10% 以内，靠字级、留白和网格撑住；错误态要另用更深的红，避免和品牌朱砂混淆。

### 方向 C · 苔庭（Moss Courtyard）

**北极星**：一座傍晚的苔庭。石台、拱门、藤影和一个站在那里的人。

**调性**：安静 3/5，精致 4/5，疏 3/5，重 4/5，庄重 2/5。依据是现有苔绿的延续，但要把“安静”做成有体积的院子，不是浅色卡片。

**标杆与取舍**：品类同上。真实对照是当前主工作台截图。外部同类没有取图。保留暖色与侧栏，换掉全部圆角卡片的形状语法，改用拱形舞台、错落踏步石和陶土输入区。

**生成引擎**：一个具体的傍晚庭院。材质是苔墙、粉笔白石灰、陶土与石台。光线从左上落下，人物站在石台上。

**首屏骨架**：

```
[ 300 苔墙侧栏 ][ 604 文案列 ][ 420 拱庭 ]
```

文案列是共同事项石牌、三行大标题、正文、三块错落的踏步石。拱庭从顶栏下方落到输入区上方，内部有石台、藤影和人物。

**字体**：

- 展示：Noto Sans SC 800，94px，行高 0.98，字距 -0.035em。
- 小标题：Noto Serif SC 38px。
- 正文：Noto Sans SC 14.5px，行高 1.85。
- 元数据：Consolas 9 至 10px。

**色彩**：

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 苔底 | `#121B15` | 侧栏与拱庭底部 |
| 苔墙 | `#26382B` | 侧栏、拱庭、共同事项石牌 |
| 粉笔白 | `#F1EDE0` | 主背景与主文字 |
| 石面 | `#E4DECB` | 踏步石 |
| 陶土 | `#C4714F` | 唯一强调色，标题落点与输入区 |
| 陶土字 | `#9E5438` | 浅底上的小字，对比度 4.74:1 |
| 浅陶土 | `#D99A7C` | 深底上的小字，对比度 5.27:1 |
| 地衣 | `#8FA07C` | 藤影与辅助线 |

**主视觉**：人物站在拱庭的石台上，脸约占 87px 宽。拱门、藤影、月光和石台共同构成一个空间，不是一张卡片。

**控件语法**：不规则圆角，踏步石用 14 至 26px 的四角不等半径，输入区是一整块陶土，模式控件收在陶土上沿。

**结构性突破**：把“舞台”做成建筑。拱庭不是容器，而是页面里最大的一个形状；标题压到 94px，与拱庭形成两个体量。

**记忆点**：“这里”下方的陶土笔触，以及三块错落的踏步石。

**放弃什么**：圆角卡片列、两枚漂浮胶囊、浅色小按钮、把人物做成贴纸。

**风险**：拱庭与陶土输入区都偏重，长对话、错误态、任务卡密集时容易抢内容。它是三者里最“海报”的方向，落地需要最多克制。

## 4. 差异检验

| | 首屏骨架 | 字体 | 色彩 | 主视觉 |
| --- | --- | --- | --- | --- |
| A | 日志侧栏 + 文案列 + 贯通观察窗 | Noto Serif SC 300 + Noto Sans SC 正文 | 夜色、深青、灯金 | 窗内的发光人物 |
| B | 索引侧栏 + 书口 + 主栏 + 图版 | Noto Serif SC 600 + Serif 正文 + Mono 页码 | 暖纸、墨、朱砂、旧金 | 深色图版与朱砂印 |
| C | 苔墙侧栏 + 粗标题 + 拱庭 | Noto Sans SC 800 + Serif 小标题 | 苔、粉笔白、陶土 | 石台上的庭院人物 |

- A 与 B 都用了右侧形象区与衬线展示字，但骨架比例、正文用字、色彩家族和装裱方式不同。更准确地说，四项里同向的是“右侧形象区”这一项；A 是轻衬线加无衬线正文，B 是粗衬线加衬线正文，两者不是同一套字体系统。
- C 走到极端，94px 无衬线标题与 420px 拱庭是三者里最强的体量选择。
- B 最明确地打破了聊天品类的默认套路。它不是“左联系人右消息”，也不是“深色底 + 紫蓝发光 + 圆角胶囊”。
- 遮住名字看画面，三个方向分别读成“夜航观察室”“手帐图版”“苔庭舞台”，不会混成同一套。

- 没有做用户偏好测试。推荐来自任务适配、辨识度、内容承载、可读性和实现代价的比较。

## 6. 推荐

**先做 B。** 理由按重要性排序：

1. **层级最清楚。** 70px 展示字、15px 正文、12px 界面字、9 至 10px 元数据形成四级落差。当前界面的主要问题是层级弱与卡片同质，B 直接从排版解决。
2. **形象第一次进入构图。** 深色图版把人物从暖纸里推出来，同时用纸边、金线和朱砂印把它解释成“被收藏的图版”，不是悬浮的贴纸。
3. **保留用户已经接受的温度。** 暖纸、侧栏、安静的语气都在。它不会像 A 那样把产品整体变冷。
4. **落地代价可控。** 80% 是 CSS 与 DOM 呈现层，渲染层只需要把现有 canvas 放进深色内衬，不需要重写 VRM。
5. **可持续。** 编号、书口、纸片、图版这些语法可以自然扩展到笔记、待办、共同事项与督办卡，不会每加一个功能就多一种卡片。

**A 排第二。** 它的氛围最强，观察窗也是三份里最完整的形象舞台。风险是它最接近上一轮已经落过又撤回的深色方向，且长文阅读与白天的使用场景需要额外验证。如果主线要更“夜”、更沉浸，A 可以回到第一。

**C 最弱，作为生产候选。** 它的颜色和拱庭很有性格，但舞台体量与陶土输入区都在抢内容，踏步石的错位在密集状态和长列表里很难保持秩序。它适合作为品牌活动页或限定主题，不适合作为每天打开的主工作台。这个判断不是说 C 不好看，是说它最难在真实状态里一直好看。

## 8. 风险与开放问题

- B 的朱砂同时承担品牌与错误语义，落地前必须把错误红调深，并保留文字说明。
- 暖纸 + 手帐容易滑向“国风模板”。控制手段是彩色面积、字级差和网格，不是再加纹理。
- 图版在真实 VRM 下可能比静态图更亮或更冷，需要按 `config/avatar.yaml` 的灯光参数现场调。
- 移动端 390px 下，图版、模式行与输入条的高度很紧。原型能放下，但真实字体缩放、安全区与中文输入法候选栏可能改变结果，需要真机复核。
- 没有验证 320px、768px 与横屏；生产落地必须补。
- A 如果回到第一，必须先解决暗色长文的阅读疲劳，并证明它与上一轮深色舞台的差异不只是换色。
- C 如果作为限定主题，建议只换主舞台与标题，输入区仍用 B 或现有控件，避免每天使用时过重。
