# 共用便笺：真实功能整合

主页侧栏现在用一个柔光容器承载此刻/笔记/待办。记忆与偏好仍保留独立语义。

2026-10-13 更新：此刻通过 `/api/activity` 恢复明确关联的便笺保存版与选定共同事项，展示新版提示、下一步和接续摘要。界面与实现范围见 [SHARED_ACTIVITY_CONTINUATION.md](SHARED_ACTIVITY_CONTINUATION.md)。

- 此刻只读明确选定的对象；未关联时提示选择，不采用最新任务替代。打开便笺链接不改变关联。
- 笔记复用同源内嵌编辑器，隐藏标签而不卸载文档，未保存输入跨标签保留。刷新页面仍可能丢失未保存输入，沿用离开提示。
- 待办复用已有任务/提醒/确认模块；任务仍由用户确认后创建。新行动结果提示标签，不主动切换编辑上下文。
- 原聊天区与输入框不受标签切换影响。

验证：test-workspace-browser.mjs 当前服务只读检查通过；test-workspace-integration.mjs 七项完整隔离检查通过，覆盖主页内嵌保存、跨标签草稿、确认前不建任务、确认后创建且在待办显示、新结果不抢焦点及角标提示。notes/task API 由测试桥接真实 FastAPI + 临时 SQLite，其他页面必要数据仅 GET；无生产写入。报告 eval/ui/workspace/integration.json。

当前边界：同页笔记保存/关联和共同事项更新会触发只读刷新，异步读取有序号保护；其他窗口的变化需要主动刷新。重新加载恢复持久选择，未保存输入仍可能丢失。笔记仍是 iframe 复用而非统一原生组件，待办仍保留展开层级。只有行动结果事件已接入标签角标，不宣称全部到期通知已有跨标签角标。未来可将表单重构成可挂载组件，不应借此自动抢焦点或丢弃草稿。
