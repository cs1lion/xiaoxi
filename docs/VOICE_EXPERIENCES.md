# 语音体验第一阶段

## 已交付的体验路径

主页面侧栏新增“语音体验”。全部使用现有按住说话/连续对话/停止回复/打断链路，不再造一个只有文字的独立聊天窗口。

### 从真实字幕进入解释与练习

1. 在字幕页选择共享音频或麦克风，获得已确认识别原文。
2. 点击某条“带这句去解释 / 练习”。临时流式原文不能带入。
3. 确认后停止共享并导航到主页面；带入选中原句以及同会话、仍在页面内的最多前2条和后2条已确认字幕。临时原文不导入，旧会话不混入；邻近文字可能按预算截取并标注。邻近内容所有字段合计最多6000字符，每条原文/译文各截取最多1400字符。
4. 原句及邻近片段通过同标签页sessionStorage一次性交接，10分钟失效，读取后删除；预览可移除邻近上下文，手动编辑原句也会清掉关联上下文，避免错误归属。
5. 核对可编辑原文（ASR可能出错），选择“一起听 / 原句解释”或“原句表达练习”，点击应用。
6. 解释围绕明确选定片段，不假装知道整部视频。原句练习要求在新场景使用表达，提示与反馈只基于文字，不评分发音。
7. 服务器确认后，“正在讨论的原句”显示实际生效的原句、译文参考与可展开的邻近字幕。听懂原句模式带有邻近字幕时，可明确点击“看原句与前后字幕的关系”，询问代词、转折与前后关系；不会自动发送问题，片段不足时仍需模型说明不确定。

这不是自动持续旁听：当前不会同时在主页面接收整场视频，也没有自动插话或视频播放器时间轴同步。清空选句仅清本地草稿；结束体验应用“普通陪聊”。

### 生效片段与可编辑草稿

上方“正在讨论的原句”以服务器确认结果为准，下方原句与邻近预览是草稿。编辑原句、译文或标签，导入另一句、恢复收藏、清除草稿、丢弃邻近字幕或修改草稿模式后，如果草稿与生效片段不一致，解释、关系和练习快捷入口会暂停，并提示重新确认应用。取消应用、发送失败或服务器拒绝时，生效预览继续显示旧片段。

等待确认期间继续编辑也不会把新草稿误当成已应用片段。体验应用通过请求编号与确认消息一一对应，普通设置回传的旧体验快照或旧请求确认不能提前解除等待。主页面直接打字或说话使用服务器当前的体验与片段；草稿提示说明修改未应用时仍使用已确认片段，等待应用期间应等确认后再提问。切到剧场、其他陪伴模式或普通聊天并获确认后，原句生效预览隐藏，关系快捷入口不可用。关系提问仅在听懂原句模式有已应用邻近字幕时开放。

WebSocket断开后，体验生效状态与预览清除，原句草稿仍留在当前页面内存，快捷入口和应用按钮禁用，迟到确认不能恢复旧会话。当前主页面没有自动重连，需要刷新并重新明确应用；刷新会丢失未收藏的草稿。

### 可插话的声音剧场

选择声音剧场，选择雨夜电台、飞船或推理预设，也可以填写自定义场景。应用后点击开始或自己开口。它使用与普通语音相同的打断能力，回复简短并让参与者选择改变故事。

这是通过提示和短会话实现的角色演绎，不是多演员音色、自动音效、背景音乐或可靠游戏规则引擎。虚构场景只在体验会话里，不进入普通聊天持久化和长期记忆。结束后切换模式清掉会话历史。

### 不抢注意力的陪伴

专注、散步、睡前、吐槽、认真讨论分别约束回复长度、提问和建议方式。体验开启时禁止普通主动轮询发言。只是响应明确用户输入，不根据麦克风静音猜情绪或擅自开口。

这些约束由LLM系统提示引导，不等于模型输出经过形式化验证；真实模型是否确实简短、自然、不越界，需要听感验收。

## 上下文与模式边界

- 每个WS连接独立体验会话，最多24组已完成问答、每条3000字符。
- 改变模式/场景/选句会清空本次体验上下文；UI应用前确认并停止旧回复。
- 原英语练习与新体验互斥，激活一个会退出另一个；关闭新体验回到原普通陪聊行为。
- 表达练习语音按请求指定英语ASR；中文求助可以使用文本。其它模式保持原ASR语言设置；无可靠自动中英切换保证。
- 体验不调用任务工具，不把问答写入常规消息或长期记忆；普通连接的session开始/结束元信息仍存在。
- 回答/TTS云服务依旧收到所需内容，服务商保留规则不由本地控制。
- LLM有25秒硬时限与每体验2个未结束调用上限；迟到结果通过会话修订及turn_id隔离。

## 原句收藏

仅点击并确认“保存原句到本机”才写localStorage，最多20条，只保存明确原文/译文/来源标签，不保存邻近字幕上下文、聊天或虚构故事。恢复只填草稿且清掉邻近上下文，不自动应用。

这是同一浏览器同源可读取的本机收藏，不是加密保险库、不跨设备同步、不等于服务端共同记忆。可以单条删除或清空；清空收藏不会删除项目已有聊天/长期记忆。敏感内容不建议收藏。

## 原创音乐

单独音乐页提供原始文字描述与用户拥有权利的歌词，调用已核验的专门音乐异步接口；默认关闭，必须由用户独立配置。开发未调用真实或付费服务。不是实时合唱、角色TTS唱歌、声音克隆或音准评估。

详见 [音乐体验](MUSIC_EXPERIENCE.md)。

## 离线验证

- `python scripts/test_experience.py`：纯会话、来源精确传递、模式提示、虚构隔离、取消、时限、音频边界。
- `python scripts/test_experience_websocket.py`：AST抽取真实路由，验证配置原子性、互斥、不进入工具/消息存储、ASR语言及晚到事件；请求编号成功/拒绝回传、普通设置不混入编号、旧客户端兼容和无效编号原子拒绝。
- `node scripts/test-experience-browser.mjs`：面板确认、服务器ack门控、单次选句交接、过期、收藏和安全文本；生效预览与草稿门控、失败/迟到确认、明确关系提问、断线失效。
- `node scripts/test-experience-entry-browser.mjs`：抽屉「陪伴体验」入口——导航切到说明视图不应用任何模式、「打开陪伴体验面板」收起抽屉并展开聚焦侧栏面板且零 config 帧、移动端自动拉开侧栏浮层且聊天区宽度不变、模式片仍为主舞台只读 span。
- `node scripts/test-interpret-browser.mjs`：字幕确认后交接，继续覆盖原分段/流式采集清理。
- `node scripts/test-voice-browser.mjs`：主页面真实体验入口使用原语音控制；关系问题沿用带turn_id的文本轮次，断线清理生效片段。

本轮“生效片段与草稿”验证：会话18项、真实WS路由20项、体验面板15组、字幕页11组、主语音页面20组通过；协议检查与本轮已跟踪改动的空白检查通过。面板在1440px与390px下无横向溢出，已审阅[桌面截图](../eval/ui/experience/applied-source-desktop.png)与[手机截图](../eval/ui/experience/applied-source-mobile.png)，截图使用隔离测试数据，不代表生产页面或真实模型回答。

不启动替代服务器、不读取私有配置、不调用模型的模拟测试不代表云模型质量、麦克风表现或生产部署已验收。重启项目后端、刷新浏览器后试用；耳机推荐，自动打断不稳定时选择仅按键打断。
