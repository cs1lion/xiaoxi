# 日常角色四种手势校准

本轮校准 `Seed-san Daily Study` 的招呼、否定、自我强调和摊掌姿势。台词意图、语音锚点、动作窗口、互斥和打断由原导演负责；姿势采样后继续使用现有实际关节过渡层。

目标姿势之后的抬起与收回路线优化另见[日常手势路线](GESTURE_PATHS.md)；本文保存上一轮姿势校准的证据。

## 原因与目标

日常模型的右上臂、前臂都沿归一化骨骼的局部 `-X` 方向延伸。旧通用姿势把前臂负 X 旋转当作主要屈肘，实际主要是轴向扭转。旧满强度动作的手腕高度只有约 0.79–0.90，而肩高约 1.23：招呼没有抬到脸侧，自我强调没有到胸前，摊掌停在外套下摆以下。

新目标按真实关节方向和手指基部测量离线编写：

| 动作 | 手部位置和表达 |
| --- | --- |
| 招呼 | 脸侧抬手，掌心朝前，小幅摆腕 |
| 否定 | 胸前抬手，掌心朝前，小幅侧摆 |
| 自我强调 | 手移到胸前，掌心朝向自己，保留衣料前方空间 |
| 摊掌 | 腰到下胸位置，掌心朝上，减少向画面外伸展和过大的腕部折角 |

`scripts/calibrate-gesture-poses.mjs` 在实际 daily 骨架上把上臂、前臂、手指和掌心方向转换为静态休息姿势相对 XYZ 角度。它只用于离线编写，结果见 `eval/avatar/gesture-authoring/poses.json`；运行时没有新增 IK 或碰撞求解。

## 实现与对照

`web/avatar/render/gesture-poses.js` 保存日常角色姿势和原通用姿势。日常角色默认启用校准；其他模型继续使用通用姿势。运行时按现有包络、语音强度和减少动态设置采样姿势。

日常角色分别编写克制和完整两个姿势，强度在这两者之间插值，保留低强度时可辨认的屈肘和转掌。插值比例为 `clamp((strength - .15) / .85)`；低于协议最小强度 .15 时再乘以 `min(1, strength / .15)`，使零强度准确回到自然姿态。动作包络继续控制抬起与收回，零权重仍为自然姿态。减少动态继续乘以 .4，摆腕幅度另随强度减弱。通用姿势保留原先的线性强度缩放。

实验页“02 / 性格与动作”提供“使用校准后的日常手势”对照开关，点击四种手势会切到半身视角。关闭后可重复同一手势查看原通用姿势。切换模型会取消未执行的实验流程。渲染器提供 `setGestureCalibration(enabled)` 与 `getGestureCalibration()`；诊断标明当前模型是否适配以及实际使用的姿势集合。

## 验证范围

固定模型、相机、灯光、表情、注视和输入动作，对比正面与左右 25° 视图；保存满强度、.4/.75 语音强度、减少动态和不同摆腕相位。记录模型与源码 hash、实际关节四元数、世界位置、屈肘角度和按手指几何推导的掌面法线。掌面法线的正反仍需结合截图确认，不能只由三角形叉积判定美术语义。

本轮不修改模型文件、原脸部、骨架映射、服装网格或权重。截图只覆盖保存的姿势及中间帧，不能证明所有动作组合都没有穿插。手指仍使用原有形状，没有新增指尖接触或抓握动画。

## 结果与证据

`node --test web/avatar/test_gesture_poses.js` 的 12 项测试通过，覆盖模型选择、实际屈肘、语音强度、减少动态、零权重与对照开关。眼睛校准、姿态过渡、语义导演、停止与 VRM 映射相关回归通过。

`node scripts/test-gesture-calibration-browser.mjs` 通过 44 个固定姿态检查，含正面、左右 25°、.4/.75 强度、减少动态、摆腕相位、半程包络，以及自我强调和摊掌的 25%/75% 抬起中间姿态。重复采样的六组手臂四元数一致；每帧测量的 1,309 个右手/手指蒙皮顶点均在检查镜头内。关闭校准恢复原四种姿势，打断从实际姿态收回。模型 SHA256 始终为 `f516bfdb7b00c87fcdbffb98c012842ca727ae835638716e704adae09271955a`。

新满强度手腕高度为：招呼 1.311、否定 1.161、自我强调 1.157、摊掌 1.069（模型世界坐标）。摊掌的实际掌面法线 Y 分量约 .923，.4/.75 强度约 .920；自我强调掌面法线 Z 分量约 -.999。掌面朝向仍结合图像复核，数值不单独代表自然度。

姿势更新后的 `node scripts/test-pose-transitions-browser.mjs` 7 组和 `node scripts/test-speech-performance-browser.mjs` 9 组回归通过，覆盖实际姿态衔接、冻结音频时钟的取消恢复、快速替换、渲染器切换和台词语音同步。对应证据保存在 `eval/avatar/pose-transitions/results.json` 与 `eval/avatar/speech-performance/results.json`。检查中没有浏览器错误、麦克风采集或 API 写入。

前后图：`eval/avatar/gesture-calibration/comparison.png`。原姿势快照源码和 20 张基线图位于 `baseline/`；新 44 张姿态图及原生关节、蒙皮投影、相机与 hash 数据位于 `calibrated/report.json`。抬起途中掌心会从休息姿态逐渐翻转，到达目标时才完整朝上；保存的代表性中间帧未见明显手部插入胸口或肩肘穿插。

袖口仍能看到灰色内缘，肘部褶皱较硬，手指偏平直。这些属于当前模型的细节限制，本轮没有将其当作服装变形、指尖接触或抓握已经完成。
