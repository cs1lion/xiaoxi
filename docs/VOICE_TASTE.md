# 语气试音台

/static/voice_taste.html：固定输入文字与 base 音色，比较自然/认真/轻松/温和。首版四种风格，不含旧七类全套试听。只在点击生成时请求 TTS，不调用聊天模型，不改默认配置，不写记忆任务；可能产生供应商费用。生成后需手动播放。

StepAudio 使用 instruction；Edge 使用 rate/pitch，不能视为同等情绪表达能力；silent 返回空音频。页面显示实际引擎、音色、参数。文本改变即撤销已有样本。字数限制240，一次生成一个样本，接口并发门控及35秒超时，失败不暴露供应商响应。

测试：test_voice_taste.py 使用fake TTS的真实路由检查，固定音色、不同指令、默认不变、未知字段/过长文本/跨源拒绝；test-voice-taste-browser.mjs 验证显式请求、无自动播放、改变文字清除样本。均通过，未生成真实供应商音频，不声称听感已验收。

2026-10-13：用户试听后选择“自然”。日常聊天的 base 指令与试听 natural 对齐，固定 livelybreezy-female；新连接默认使用 TTS_DEFAULT_EMOTION（默认 base），主页面显示为“自然”。语气选项通过 config.emotion 传入当前连接，每轮开始时固定本轮的语音选择，仅控制 TTS，不改变文本处理或角色表情。空字符串选择自动随内容变化；其它 config 更新保留当前选择，无效语气不应用。英语练习和语音体验仍沿用各自的专用表演指令。
