# 日常角色脸部亮部校准

日期：2026-10-14。适用模型：`seed-daily.vrm` / `Seed-san Daily Study`。

本轮改善脸部亮部泛白，让鼻子和嘴部的淡线更容易辨认。仍使用现有 Three.js / MToon 渲染，变化幅度较小，保留原有暖光画风。

## 依据与选择

使用同一模型、560×680 画面和固定姿态，比较普通暖光、左侧光、右侧光，各自检查正面与左右 25° 视角，以及自然和开心两种表情。左右视角通过相机绕脸部中心移动建立；另用真实头骨、眨眼和口型驱动检查动态。

原版普通光正面两个固定采样区的红通道接近全部截顶：额头 100%，脸颊 99.955%。这个结果支持优先处理脸部亮部曝光。当前画面没有足够证据要求改面部法线；已有 `body_shadeshift` 是静态阴影阈值遮罩，不能等同于方向驱动的 SDF。

降低全局灯光会同时使头发、眼睛和衣服偏灰；单独调整卡渲阈值或减弱描边没有得到明确收益。因此最终保留灯光，只将两个脸部 MToon 实例的 `color` 与 `shadeColorFactor` 从各自原始值在线性空间乘 **0.90**。这个系数不等于观感亮度下降 10%。

候选同一采样区的红通道截顶比例降到 0%；额头平均 RGB 从 `(255.00, 232.12, 204.46)` 降到 `(249.53, 221.51, 195.02)`，脸颊从 `(254.98, 226.39, 200.11)` 降到 `(244.78, 216.09, 190.81)`。这是固定区域的结果，不能推论所有角度或任意灯光都已消除过曝。

## 实现与使用

实验室“01 / 渲染与模型”提供默认开启的 **脸部亮部校准**，关闭即可对照原版。开关保留当前相机与姿态，可在转头、眨眼和口型中观察差别。未适配模型禁用该控件。

- `VrmRig` 只匹配日常模型的 `body_bake` 与独立的 `body_bake (Outline)`，遍历时对共享材质实例去重。
- 两种模式都从加载时捕获的原始颜色计算；反复开关不会累计变暗，也不创建新材质。
- 灯光、相机、几何、法线、贴图、阴影阈值和描边宽度保持原值；现有眼神、口型、手臂、手指与上身动作继续工作。
- 固定校准保存选定模式和实际材质颜色，并在退出时恢复完整精度数据。颜色与阴影颜色均参与固定场景指纹；校准期间实验室禁用外部控件，避免混用两种画面条件。

模型文件未修改，SHA-256：`f516bfdb7b00c87fcdbffb98c012842ca727ae835638716e704adae09271955a`。

## 证据与验证

证据位于 `eval/avatar/face-shading/`，包含冻结的修改前源码、实际 PNG、材质审计、固定采样区数据与浏览器检查报告。截图来自生产 VRM 渲染器，没有使用绘制替身或图片插值。

CPU 回归已通过 114 组，包括 6 组新增的真实 Three.js / MToon 集成测试：反复开关与精确恢复、模型与材质匹配范围、校准恢复、阴影颜色指纹，以及生产转头/眨眼/口型驱动一致性。

固定的 18 组画面中，相机、灯光、几何、法线、骨骼与形变参数在修改前后保持一致；只有指定脸部材质的两个颜色系数发生变化。三种灯光下各使用 181 步、60Hz 的确定性动画步进，前后驱动输入、骨骼、表情与形变权重一致，按每 6 步保存一张实际渲染图。这是动作检查，不能用来宣称真机达到了 60 FPS。

独立审图检查了所有 18 组静帧和三种灯光下的多个动态采样，包含开心侧面、眨眼闭合附近与开口中间帧；未观察到新增的鼻翼/眼窝黑斑、脸颊阴影断裂、描边跳变或开口颜色异常。当前验收范围是上述相机与灯光条件。

- [静态前后对照](../eval/avatar/face-shading/before-after.png)：左原版，右校准，包含普通光正面与左右侧光视角。
- [转头、眨眼、开口前后 GIF](../eval/avatar/face-shading/face-shading-dynamic-comparison.gif)：左原版，右校准，使用实际渲染帧。
- [CPU 回归记录及完整命令](../eval/avatar/face-shading/cpu-regressions.json)。

脸部浏览器检查 6 组通过，包含反复开关精确恢复、固定场景指纹、校准退出恢复和灯光预设组合；页面操作、模型切换与校准控件保护 3 组通过。检查未申请麦克风，也未调用真实语音或写入 API。

验证还复现了一个既有边界：部分旧弹簧骨在退出固定校准时，局部变换恢复但缓存的世界矩阵未完全恢复。冻结的修改前版本与当前版本均出现该行为；这些旧骨骼对活动索引顶点的正权重为零，所有映射人形关节和可见 Mesh/SkinnedMesh 世界变换恢复一致，脸部颜色与模式也精确恢复。该问题记录在 [旧弹簧骨缓存复现](../eval/avatar/face-shading/legacy-calibration-cache.json)，需要在后续给前发添加有效蒙皮之前处理。

最终手型、动作衔接和台词动作的浏览器回归结果待写入后补充。
