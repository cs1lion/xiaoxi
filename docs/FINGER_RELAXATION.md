# 日常角色的手指松弛

这一步为日常角色增加轻微的手指弯曲：休息时各指分别放松，表达时右手随原动作包络舒展，收回时恢复放松。它使用现有骨架和蒙皮，保留上一轮肩肘腕路线、动作终点和语音安排。

## 骨架依据与范围

静态 GLB 审计见 `eval/avatar/finger-relaxation/audit.json`，复现脚本为同目录的 `audit_model.py`。Daily 模型两侧各有 15 个映射手指节点，所有指节均对有效手部网格有直接皮肤权重。普通末节每侧有 114 个强权重顶点；这些数字验证蒙皮接入，不证明动作的视觉自然度。

这次操作食指、中指、无名指和小指各三节，共 24 个 normalized 节点。原四指沿 normalized 的 ±X 方向，向掌内弯曲可使用右手 +Z、左手 −Z。Raw 骨骼的绑定方向和局部旋转不同，运行时不直接改 raw 节点。拇指的弯曲轴为 X/Z 对角方向，本轮保留其原姿态。

骨架支持逐指、逐关节独立旋转，双手共 30 个已映射且有蒙皮权重的手指节点。该阶段只使用四指轻弯/舒展；后续[拇指与基础手型](HAND_POSES.md)接入六个拇指节点，以及放松、摊掌、轻握检查。指向、闭拳、捏合与接触仍需进一步标定，不需要因此换骨架。

## 姿态与驱动

`web/avatar/render/finger-poses.js` 保存各指的轻弯幅度（近节/中节/末节，弧度）：

| 手指 | 休息幅度 |
| --- | --- |
| 食指 | .08 / .10 / .05 |
| 中指 | .12 / .16 / .08 |
| 无名指 | .16 / .20 / .10 |
| 小指 | .20 / .24 / .12 |

满强度招呼、否定保留休息弯曲的 .2，摊掌保留 .55，自我强调保留 .85。普通语音强度的手指稍多保留弯曲；低于 .15 强度时连续减弱表达变化，零强度恢复休息。左手继续放松，右手按现有动作包络在休息与表达之间插值，没有独立的手指摆动周期。减少动态保留轻弯休息姿态，只把表达变化乘以 .4。

渲染器在模型加载时捕获每个可用 normalized 指节的绑定四元数，再合成相对偏移。实际节点以 `1-exp(-18*safeDelta(dt))` 逐帧接近目标，沿用渲染帧时间的 .05 秒上限。打断使目标立即改为轻弯休息，身体恢复无需推进音频时钟。设置改变时不重置手臂过渡，不修改瞬时关节姿态。

接口为 `setFingerRelaxation(enabled)` 与 `getFingerRelaxation()`，后者返回 `{available, enabled}`。它只适配精确 Daily 模型且存在可用指节的情况；缺少部分指节会跳过，其他模型不写手指。关闭时平滑回到原绑定姿态，开启时平滑进入轻弯姿态。该设置独立于手臂姿势校准和路线开关，眼睛校准进入/退出时会保存和恢复。

## 对照与检查

实验页 `http://127.0.0.1:8000/static/avatar_lab.html?model=daily&preview=gestures` 的“02 / 性格与动作”增加“手指自然松弛”。可在相同动作下切换，比较平直手指与轻弯手指。

单元检查命令：

```powershell
node --experimental-default-type=module --test web/avatar/test_finger_poses.js web/avatar/test_finger_rig.js web/avatar/test_calibration.js
```

纯采样测试覆盖模型范围、左右镜像、各指幅度、舒展、连续强度、减少动态、取消和有限输出；实际节点测试覆盖绑定姿态合成、缺失节点、零帧时间、模式切换、取消恢复以及手臂过渡不被手指控制重启。校准测试检查退出恢复此前的开关。

浏览器检查使用真实 Daily 模型与生产导演/渲染器，保存手部近景、动态前后对照、原生指节与蒙皮数据；证据位于 `eval/avatar/finger-relaxation/`。骨骼数值有限和具有蒙皮权重不能代替近景确认：需要检查弯曲方向、皮肤折叠、指间穿插，以及手部靠近衣服时的间距。

近景对照以渲染器捕获的原绑定四元数计算固定的掌面与镜头参考；动态从已稳定的放松姿态开始。截图前统一刷新实际姿态的蒙皮包围范围，避免紧镜头使用旧休息范围裁掉袖口。`before/cuff-audit.json` 记录了同一镜头和相同的 198 个袖口顶点：旧范围使袖口视锥检测失败，关闭裁剪或刷新范围均恢复显示，顶点变化为零。旧参考图保存在 `old-reference/`，不作为最终前后对照；生产渲染器和袖口蒙皮未因此更改。

本轮通过 47 项手指采样、节点驱动、校准恢复、手臂路线与姿态单元检查。完整浏览器结果为 `after/report.json` 的 6 组检查：13 个定姿的全身/近景/侧视对照、两段按 60 Hz 运行的真实导演/渲染器序列、左手原始/放松近景、关闭与缺失适配、原生音频时钟暂停后的打断恢复和实验页开关。浏览器错误、麦克风请求与 API 写入均为零。

随后顺序通过原有过渡浏览器检查 7 组、语音表演浏览器检查 9 组。动态前后对照为 `self-comparison.gif` 与 `palm-comparison.gif`，逐帧交互检查为 `comparison.html`；`hand-comparison.png` 和 `edge-comparison.png` 汇总五种静态手型。所有图像均来自实际模型渲染。

前后实际归一化和 raw 手臂序列一致，近景机位、袖口/衣袖加权骨骼与实际蒙皮顶点一致，拇指姿态和模型文件哈希未变。该阶段证据记录的渲染器、手指模块、手臂模块与模型哈希已同验证时的文件核对；后续上身配合单独记录其增量。左右手静止以及右手表达近景未见新增的明显指间或衣物穿插；这仅描述已检查的机位和动作，不能代替碰撞求解。

本轮没有握拳、指向、触碰身体或抓取物体，没有手指碰撞求解与新蒙皮。拇指、掌骨结构和皮肤拓扑保留原样；自然感仍受上身静止、转掌速度与模型手部细节影响。
