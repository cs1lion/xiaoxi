# 半身对话表演 / 阶段一

## 阶段范围

实现可中断的交流表演原型，以 Seed-san 作功能底模，不宣称原创脸部设计、忍野忍比例建模或专业动画已完成。不包含桌面窗口实现。

入口：http://127.0.0.1:8000/static/avatar_lab.html?model=seed

## 已实现

- 独立 PerformanceDirector：不依赖 DOM，使用音频时钟安排手势。
- 状态：idle / listening / thinking / speaking。
- 四种通用骨骼试作：招呼、轻摊手、否定、自我强调。
- 在 Avatar.speak 的实际播放入口按当前情绪和句子特征选择手势，有冷却和缓入缓出。
- recording、thinking、interrupted 等事件可以清除动作；打断后手臂平滑回到休息姿势，口型停止。
- VRM normalized arm bones 相对休息姿态执行；缺骨骼时降级，减少动态模式缩小幅度。
- 实验室流程：待机→倾听→思考→调侃回答→用户打断→重新倾听。使用静音口型，不是生成 TTS。
- 可切换柔和照明/近景：只改灯光和相机，不修改资产。不包含此前设想的描边或服装改造。

## 真实能力边界

当前行为选择是规则式、句子级的高层原型，不是完整 LLM 意图协议，也没有音节重音时间标注。四种手势是通用骨骼角度，不是专业手工动画；不含手指动作、IK 接触或逐模型视觉校准。眼神和基础表情复用已有驱动。聊天页的默认模型选择没有改变，Seed-san 仍在实验室验证。

此会话图像读取不可用，截图不能作为人工美术质量验收证据。模型数据、时序和浏览器运行已验证，但具体手掌朝向、衣服穿插、镜头裁切应人工查看后再校准。没有承诺几何加载成功等于动作自然。
