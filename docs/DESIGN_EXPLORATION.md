# 可判断、可拆卸的设计探索 · 第一批

## 使用

保留主地址 `http://127.0.0.1:8000/` 为已确认基线。打开 `http://127.0.0.1:8000/?explore=1` 后点击右上角「设计探索」。没有启动或替换服务器。

组合预设：
- 安静书桌：暖纸色 + 纹理 + 环境光。
- 灵动伙伴：紫粉色 + 环境光 + 角色光环 + 弹性反馈。
- 未来空间：深蓝色 + 环境光 + 玻璃层次 + 角色光环 + 弹性反馈。

这些是候选，不是最终设计。可以故意混搭纸感和玻璃，观察冲突；不用预先断言哪个更好。角色光环只改变舞台皮肤，不增加角色行为。

## 比较与记录

1. 选择预设，收起实验面板，用同一段真实聊天体验。
2. 独立撤下某个材料，判断好坏是来自色彩、材质还是运动。
3. 按住「看基线」暂时清除所有实验属性，松开恢复；支持鼠标、触摸和空格/Enter。
4. 输入判断，点击「记录当前判断」。切换不会删除尚未写完的判断。
5. 「导出实验记录」下载 JSON，包含每条判断的预设、实际效果集合、时间，以及当前状态。

记录只在本页内存，刷新即丢失。不会写入角色记忆或服务端。卸载前请导出。

建议每个组合体验：首屏 → 聊天十分钟 → 长消息 → 翻阅历史 → 手机 → 等待/错误。记录“保留/删除/改进什么，为什么”，不要只有好看/不好看。

## 工程隔离与拆卸契约

- 唯一主页面接入点：index.html 末尾按 `explore=1` 条件动态 import。
- explore.js 独立定义 effects 和 presets；不导入 app.js 或角色驱动，不操作 API、麦克风、摄像头和发送流程。
- explore.css 只有实验面板类与 `data-explore-tone` / `data-fx-*` 作用域规则；普通 URL 不加载它。
- 每项效果对应一个属性。关闭即删除属性，不向业务元素写 inline style。
- 「全部撤下」清除 tone 和所有效果属性，保留面板用于继续比较。
- 「卸载实验层」清除属性、撤销事件监听、移除面板/按钮/样式表、移除 URL 参数；不刷新、不清空草稿。
- 要永久拆掉入口，删除 index.html 的探索 script 区块即可；实验模块与 CSS 此后不再下载。
- 新效果必须用独立属性、提供撤下行为、验证减少动态与组合；不要注册全局不可撤销计时器或修改核心业务状态。

当前实验层无新外部依赖、无循环动画、无持久化偏好。backdrop-filter 和 color-mix 不支持时主要视觉退化，不是核心操作前提。

## 验证证据

运行 `node scripts/test-explore-browser.mjs`：53 项检查通过。
- 普通 URL 不加载实验模块，无实验控件。
- 三种 tone 生效，切换保留草稿。
- 所有 32 种五效果组合无页面横向溢出（1440px）。
- 按住对照/全部撤下恢复精确基线 stage background。
- 导出包含三条比较记录。
- 未来空间 390px 无页面横向溢出。
- Esc 关闭面板，实验启用时文本发送继续可用。
- 运行时卸载删除 launcher / CSS / URL 参数。
- 受控 WebSocket + 偏好/列表模拟 API，无真实写入或模型请求。
