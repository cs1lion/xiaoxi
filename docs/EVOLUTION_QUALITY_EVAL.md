# Autonomous Mind V2 · 自主进化质量评估记录

自动化测试（`scripts/test_evolution_soak.py` 等）只验证**机制**：能否裂变、去重、追溯、
跨来源连线、失败不假成功、资源有界。**机制通过 ≠ 思想质量合格。** 本文件是主观质量的独立评估记录，
四个维度分别判定；通过标准写清楚，便于真实使用后复盘。

## 四个维度与通过标准

1. **来源相关性（Source relevance）**：反思/子种子/顿悟必须挂在**真实存在的** Seed、日记、Note、
   Thread、Ledger 上；`source_refs` 指向的 ID 真实存在，且内容确实支撑该结论。不得挂空引用或张冠李戴。
2. **子问题新颖性（Child novelty）**：派生的子问题是一个**真正不同**的问题，不是原问题或既有种子的
   近义改写；能打开新的思考分支。近义繁殖应被 `similarity_dedupe` 挡下。
3. **推理连贯性（Reasoning coherence）**：从材料到发现到子问题，因果链读得通；发现确实由所选材料支撑，
   不是跳步或套话。
4. **无空洞泛化（No hollow generalization）**：叙事/发现是具体的、带着这次材料的细节，而不是放之四海而皆准的
   空话（如“人生需要平衡”这类无信息量总结）。

## 当前评估（2026-10-15，受控数据 / 离线）

> 说明：本环境为离线 mock 模式，无真实 LLM。以下样例来自 `test_evolution_soak.py` 的**受控脚本数据**，
> 因此只能评估**管线是否正确保留并关联了真实来源**，**不能**代表真实模型的生成质量。真实质量需在一次
> 接通 LLM 的真实运行后，按本记录模板补录。

**实际来源链（浸泡测试产出，可追溯）**：

```text
seed:seed_night_decisions  "观察人类为什么总喜欢在深夜做推翻白天的决定？"   (config/seeds.yaml)
  + diary:2026-10-13       "他又半夜改稿 …… 凌晨又打开。"                    (用户共同经历)
  + note:n1                "今天一天被消息打断十几次，根本没进入状态。"        (用户笔记)
  -> reflection:refl_*     discovery="他深夜改稿可能和白天被打断有关"
  -> child seed            "一个人终于获得不被打断的时间时，判断会怎么变？"    (parent=seed_night_decisions)
  -> epiphany edge         diary:2026-10-13 <-> note:n1  "日记与笔记共同指向同一个判断变化"
```

| 维度 | 判定 | 依据 |
|---|---|---|
| 来源相关性 | **通过（管线层）** | child 的 `parent_seed_ids`/`source_refs` 与 epiphany 边均指向真实存在的 seed/diary/note；`test_evolution_soak` 断言了可追溯。 |
| 子问题新颖性 | **通过（机制层）** | 子问题“不被打断时判断怎么变”与原问题“为什么深夜推翻白天”是不同问题；近义改写被 `test_no_near_synonym_proliferation` 挡下。 |
| 推理连贯性 | **待真实 LLM 评定** | 脚本发现“与白天被打断有关”到子问题因果通顺，但为人工构造，不能证明模型稳定复现。 |
| 无空洞泛化 | **待真实 LLM 评定** | 脚本叙事具体，但需真实运行抽样检查是否出现套话。 |

## 真实运行后补录模板

- 抽样 N 轮反思（建议 N≥10），逐轮记录：`reflection_id`、选中 Seed、`source_refs` 及每条是否真实存在。
- 对每轮按四维度打标 + 一句话理由；统计各维度通过率。
- 记录任何“挂空引用 / 近义繁殖 / 跳步推理 / 空洞泛化”的具体样例，回流为契约或去重阈值的调整依据。
- 只有在“来源相关性 + 无空洞泛化”通过率达标后，才认为思想质量合格；否则回到 prompt / 选材 / 去重阈值调整。
