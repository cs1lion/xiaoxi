# 英语口语搭档 MVP

主线转向语音语言体验，不扩展文件执行代理。本轮不是实时同传，也不是歌声合成。

## 使用

重启项目后端，刷新页面，展开“声音与形象 → 英语口语搭档”。选择自由聊、咖啡店或面试；难度A2/B1/B2只是回复难度偏好，不是测级。选择不纠错、回顾时纠错或对话中轻度纠错，应用设置后开始说话/打字。

- 改变场景、等级或纠错方式会清空练习上下文；相同设置不会清空。退回普通陪聊也清空。
- 连续监听时等待1.6/2.2/3秒安静收句，默认2.2秒；普通聊天仍900ms。改等待值应在不录音时操作。
- 仍有29.5秒客户端/30秒服务端单次录音上限。不是无限长口述。
- 中文求助可打字，模型被要求简短中文解释后回到英语。练习录音按次指定ASR英语，避免全局中文设置；中英混说可能识别差，尚未实际验收。
- 点击“回顾本次表达”生成文字反馈；不会自动退出练习，也暂不朗读反馈。可继续练习。
- 练习模式不调用任务工具、不注入共同事项、不读写长期记忆、不调用普通聊天消息存储。最多在当前WS连接内保留24个完整往返；断线丢失，模型服务商日志不由此开关控制。

## 反馈边界

模型给最多3条quote/suggestion/reason；quote必须逐字出现在保留的用户文字中，不能引用助手台词冒充用户。缺失来源/格式无效整批拒绝；活动数量由程序计算，不采信模型总结。

这只校验出处，不证明改法语法上一定正确。ASR转写也可能有误，应先核对文字。没有音素/发音评估，不提供发音、流利度分数或等级鉴定。纠错关闭时回顾只显示活动摘要、不调用纠错模型。

## 音频与交互边界

复用现有ASR/TTS配置，不安装新模型或更改音色。不同供应商英语语音质量/语言参数支持需真机验证。当前练习先等完整短回复生成，再分段TTS，首声可能慢于原来的流式聊天；不是端到端实时音频模型。TTS失败时保留文字并提示，模型离线时明确不可用，不伪造练习。

练习回复/回顾绑定turn_id与会话revision；模式切换或抢话后的迟到模型/音频不再写回。只在回复完成后保留该轮历史，取消轮可能不进入回顾。历史不等于播放完成回执，不声称用户听完。

页面仍显示先前聊天，但练习上下文单独维护。关闭练习后普通聊天仍按原行为执行和记忆，用户应注意模式提示。

## 测试

- `scripts/test_practice.py`：10项，提示场景、配置原子性、隔离与上限、引用来源、取消、离线和TTS失败。
- `scripts/test_practice_websocket.py`：真实app定义的AST隔离测试，覆盖任务/存储绕过、config、回顾、旧轮屏蔽、ASR按次英语参数。
- `scripts/test-voice-browser.mjs`：17组浏览器模拟，包括设置、较长停顿、回顾turn_id和退出。
- 原 `scripts/test_voice_turns.py` 25项及协议检查通过。

测试使用模拟模型、合成音频与临时环境，不调用云模型、不验证真实口音、麦克风、英语ASR/TTS质量。下一步应先做真实短句/中英混说/口音样本评估，再选更合适的流式模型；翻译和歌唱应各有独立模式和验收标准。
