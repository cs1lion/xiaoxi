# UI 视觉审计与设计方向（2026-10-17）

对象：`http://127.0.0.1:8000/` 主工作台，1440×1000 与 390×844 两档。
方法：Playwright 打开真实页面，只对 REST/WS 做空状态夹具，不写库、不请求模型；
截图与量化读数在 `eval/visual-audit-20261017/`，修前图见 `eval/ui/preview-desktop.png`。

## 1. 结论

主界面的“暖纸 + 苔绿 + 衬线标题”方向是成立的，不需要换视觉语言。问题集中在**表面与文字
用了两套主题**：深色 Holo 表面（`rgba(28,39,64,.92)`）配了亮色主题的 `--text`/`--muted`，
出现深底深字。另有两处布局问题：移动端头像压到建议卡，底部两枚模式胶囊上下分离。

本轮修掉 P0 可读性事故与移动端头像重叠，不新增按钮、不改业务状态。

## 3. 问题清单

### P0 · 深色表面配深色文字

- `web/companion.css` 的 `.companion-panel` 背景 `#1c2740eb`，文字继承 `--text`；标题、提示、
  折叠摘要全部落在 1–2:1。
- `.presence-capsule` 同样是 `rgba(28,39,64,.72)` + `var(--text)`。这枚胶囊在输入框上方，
  是用户最常点到的模式控件之一，必须能读。

**修复**：把“正在一起做”还原为暖纸卡（`#f4f2e7`，左侧 3px 暖棕内阴影），文字回到
`--text`/`--muted`；保留“灵动伴随”为唯一深色玻璃胶囊，文字改为 `#f6f1e4`。

修后读数：

| 项 | 修后 | 目标 |
|---|---|---|
| 面板标题 | **10.13:1** | ≥4.5 |
| 面板提示 | **4.97:1** | ≥4.5 |
| 胶囊文字 | 深底亮字，约 9:1 | ≥4.5 |

### P1 · 移动端头像压住建议卡

390px 下 `.avatar-stage` 是 120×190、`right:0`，与首张建议卡水平重叠 22px；它既挡内容，
又没有真正参与构图。

**修复**：390px 下缩到 96×160、`right:0`、`opacity:.62`，并把纵向位置抬到
`bottom:236px`。修后头像 x=294..390，卡片 x=22..292，留 2px 间隙；页面
`scrollWidth=390`，无横向溢出。

### P1 · 两枚模式控件上下分离（未修，列为方向）

`#modeStrip`（“连续对话：关”）与 `#presenceCapsule`（“灵动伴随”）是两行独立的块，
都漂在输入框上方，视觉上像两组遗留控件。方向是把它们收进同一行“当前怎么陪”：
一个主状态（灵动/静默/无痕）+ 一个连续对话开关；不再增加第三枚。

### P2 · 桌面头像与对话没有关系（未修，列为方向）

240×340 的头像固定在右下，脸部约 55px 宽；它既不是对话的一部分，也没有被构图接住。
方向见 Avatar 审计：要么在说话时给一个明确的中景，要么把它缩成“在这里”的小 presence，
不要维持“一直站在角落”的中间态。

### P2 · 设置面板在移动端占满整屏（未修，列为方向）

390px 下设置面板 `top:64px; bottom:` 覆盖几乎整个视口，底部还能看到模式胶囊。
方向是分成“形象 / 声音 / 练习”三个短页签，或改成从底部升起的半屏 sheet；
本轮不动结构，避免引入新的导航层级。

## 4. 设计方向

**一句话：一张暖纸，一个深色玻璃状态胶囊，头像只在对的时刻占画面。**

1. **表面规则**：暖纸承载内容；深色只留给“当前陪伴状态”这一枚小胶囊。
   任何深色表面必须显式声明 on-dark 文字，不允许继承亮色主题的 `--text`。
2. **一个主动作**：空状态的主动作是“说一句话”，其次是三条建议；共同事项卡是背景任务，
   不应该比标题更响。修后已从“全页最黑的块”降为“暖纸卡”。
3. **头像有位置**：桌面主舞台保持右下，但加地面阴影；说话/思考时再放大或前移。
   移动端只做“在角落陪着”的小图，宽度不超过 100px，且不得压住可点区域。
4. **模式收敛**：灵动/静默/无痕是一个状态，连续对话是一个开关；两者可以同排，
   但不要各自长成一枚大胶囊。下一步再动结构，先保留现有可达性。
5. **不新增顶栏按钮**：所有入口继续走工作台抽屉与设置面板。

## 7. 还没验证的

- 这是空状态截图，不是长对话/真实语音播放中的视觉验收；动态卡片、打断态、错误态未重拍。
- 对比度是两处文本的局部测量，不是全页 WCAG 审计。
- 移动端头像的 2px 间隙在真实设备字体缩放/安全区下可能变化，需要真机复核。
- 两枚模式控件的合并只是方向，没有实施；不要把它写成“已优化”。
