# 动态上下文预算与本轮参考

2026-10-14。普通对话与行动助手决策的自动上下文现在经过一个共享收口：在既有分域准入之后，统一限定动态补充资料，并从最后实际提供的数据生成来源清单。它帮助排查漏用、串用和版本错误，不证明模型已经正确理解或引用这些资料。

## 用户能看到什么

普通回答和经过模型决策的助手结果下方有折叠的「本轮参考」。展开后可见：

- 本轮提供的记忆、场景偏好、共同事项、事项记录、笔记保存版及待办的 ID 与选择规则。
- 稿件的固定保存版本、用途，以及是否提供了正文片段。只提供索引时不会标成已读正文。
- 动态上下文字符用量、因共享预算省略的条目数；各资料视图的历史/材料省略合计另列，可能包含同一批预算裁减，不能相加。
- 正文上游截取的提示，以及清单本身未展示的数量。清单未展示与模型没有收到资料是两种情况。

笔记链接打开指定保存版本；事项链接只读打开原事项的管理页，页面可显示之后的修订，不会自动改选全局事项。记忆、偏好和待办入口定位页面已有管理列表，缺失时说明找不到，不为展示再请求私有正文。

清单只包含白名单身份、版本、来源状态及规则码，不复制标题、正文、原话、会话 ID、评分或提示词。最多 32 项，序列化条目合计最多 4000 字符。它不是模型思考过程，也不产生工具授权。离线助手、确定性接续说明和没有调用模型的操作不新增「已提供模型」清单；独立笔记/事项候选解析仍沿用自己的入口。

## 预算准确覆盖哪里

共享上限为 **12000 字符**，计量对象是最终动态投影的序列化形式，不是 token、费用或整份模型请求。

| 路径 | 本轮计量 |
| --- | --- |
| 普通对话，流式与非流式一致 | 动态行为策略、状态要求、记忆/事项/活动数据消息及近期历史组成的消息列表，按紧凑 JSON 计字符，包含消息包装和转义 |
| 行动助手决策 | 提供给模型的补充 `context` 紧凑 JSON，加一次渲染后的行为策略字符数 |

普通对话的静态角色提示、完整当前请求不计入该补充预算。行动助手的静态决策规则、原始请求、最新答复、完整运行澄清历史、工具定义与真实执行回执属于执行核心，保留在外层，不因补充资料过多被裁减。完整请求因此仍可能超过 12000 字符，服务商上下文窗口及输出限制另外适用。

原有分域限制继续生效：普通记忆默认 600 字符，助手最多六条记忆且单条完整值最多 320 字；事项视图、当前稿和参考资料各有本地准入限制。共享预算不能找回上游未准入的信息。笔记正文仍可能是明确标注的片段；模型必须承认缺失条件，不能补写后文。

共享裁减按完整条目进行：先示例、较旧历史及较低优先级记忆/待办，再事项历史和事件、重复索引，最后明确请求的资料正文。记忆记录、历史消息和事件的版本包不会切成半条；事项上游仍可能按原准入规则省略中间完整版本，保留包的版本省略另有计数。若必要身份与边界仍无法容纳，则显式失败，不能换目标或截去关键身份。

## 接续与来源边界

事项资料与行为要求分开，正文作为不可信 user 数据提供。行为策略只渲染一次；事项不再同时藏在策略 JSON 和独立资料中。捕获事项后，策略协调器不再重新读取另一个页面的选择。

行动运行在预算之前捕获原事项、笔记保存版和材料来源。正文被省略或记忆暂时关闭，不清掉有效运行绑定，也不采用之后新选的稿件。解除、换用途/版本、删除等来源校验仍适用。旧运行若只有个人笔记引用、没有事项材料归属，继续停止读取该旧稿，不猜补归属。

检索候选不会立即增加「已使用」次数。普通对话只标记最终准入记录；助手在实际组装模型决策输入时标记准入记录。该计数表示提供为上下文，不代表模型引用正确。关闭记忆时，两条自动入口不读长期记忆、场景偏好、事项或活动资料；关闭时的主动发言也不会搜索这些来源。执行时区与当前行动配置继续独立读取。

编辑器讨论、字幕体验、练习、专用笔记/事项修改解析及主动发言仍有自己的资料边界；本轮没有把这些入口并入普通上下文，也没有增加检索算法、项目 schema、后台采集或自动持久化。

## 验证与下一步

新纯预算测试覆盖完整条目、省略状态、固定身份、白名单 trace、实际 renderer 计量、禁用和过小预算。新集成测试抓取真实最终提示，使用内存/临时 SQLite、假模型和假语音，覆盖两条路径、执行核心、来源计数及特殊模式隔离。浏览器使用合成响应，检查折叠清单、固定版链接、管理定位、焦点与草稿保持、移动端及不可信内容。

去重共 **318 项 Python 检查通过**，包括纯预算 16 项、最终提示接缝 12 项和[阅读试用闭环](READING_HABIT_TWO_WEEK_TRIAL.md) 6 项。主批 310 项通过后新增历史版本省略计数与试用闭环检查，预算与接缝 28 项复跑全部通过，复跑不重复累计。覆盖回应策略、偏好、助手上下文/澄清/API/WebSocket、活动范围与对话、事项跨连接接续、记忆检索/证据/投影、笔记修改及语音交付。旧测试的捕获点改为真实最终提示或实际 broker，不恢复已经拆开的旧组装入口。

离线浏览器共 **117 组通过**：本轮参考 8、助手 1 总体组、共同事项 31、笔记候选 33、助手确认 7、语音页面 37。专用结果在[浏览器报告](../eval/ui/context-usage/results.json)。复跑不累计为新增检查。这些是相关范围的离线验收，不是全项目检查通过；既有形象协议/空白问题仍未纳入修复。

语法、局部空白和本轮文档链接检查通过。没有调用付费模型/TTS、采集麦克风、读取真实用户库或密钥、部署或重启服务。
