# Avatar 3D 视觉审计与方向（2026-10-17）

对象：`Seed-san Daily` 衍生造型（`seed-daily-lids`），Avatar Lab 1280×920 与主工作台 1440×1000。
方法：Playwright 真实加载 VRM，截正面、眼部近景、视线跟随、主舞台四组图；只读，不改模型资产。
截图在 `eval/visual-audit-20261017/`。

## 1. 结论

模型的眼睛（虹膜、高光、LookAt）已经能承担情绪，问题是**轮廓和嘴**：

- 前发是一块带硬折线的三角片，额头处有明显接缝，左右鬓角与脸之间有缝；这是最像“未完成资产”
  的地方，优先级高于任何 shader 微调。
- 静止时嘴几乎不可见，配合略平直的粗眉，默认读成“平淡/担忧”，不像陪伴角色。
- 额头有一块偏白高光，头发在额头没有投影，前后景像贴纸；主舞台又太小、没有地面接触。

本轮只做了低成本的主舞台地面阴影；发际线、嘴、光影需要改资产/材质，先定可测量目标，不在
没有对照的情况下大改。

## 2. 观察与证据

### 2.1 正面（`avatar-lab-front.png` / `avatar-lab-stage.png`）

- 脸型、眼睛比例、发色都稳定；眼睛高光偏大但可爱，符合角色。
- 前发从头顶到额头是一整块硬边多边形，中央有一条可见折线；左侧鬓角与脸颊之间透出背景。
- 眉毛粗、直、略向下压；默认没有笑意。
- 嘴是一条非常淡的短线，在 1280 宽的舞台图里几乎看不见。

### 2.2 近景（`avatar-lab-face.png` / `avatar-lab-gaze.png`）

- 额头到眉骨是一块偏白的亮区，和脸颊的暖色之间有比较硬的过渡；像“打了高光”，不是头发投影。
- 头发在额头没有投影，发片像贴在皮肤上；眼睛下方有很轻的腮红。
- 右眼（画面右侧）上睑的睫毛有一段偏尖的黑色延伸，左右不完全对称；近景可见。
- 视线跟随有效，眼球移动时高光位置稳定，没有穿模。

### 2.3 主舞台（`main-vrm-avatar.png` / `main-vrm-desktop.png`）

- 舞台 240×340，头高约 80px、脸宽约 55px；在 1440 页面里读不清表情。
- 身体到中腿被输入框截断，脚下没有明显接触阴影；角色像浮在纸面上。
- 3/4 站姿、手自然下垂，轮廓干净； outfit 的米白/藏青与页面暖纸协调。

## 3. 方向

**一句话：暖色赛璐璐的日常陪伴者，先修轮廓，再修嘴，最后修光。**

### P0 · 发际线轮廓（最高优先）

目标：

- 1280 正面图中，前发内缘是一条连续曲线，**没有**横穿额头的硬折线；中央发缝只在头顶出现，
  不延伸到额头。
- 左右鬓角与脸颊之间不留背景缝；发片厚度至少覆盖到耳前。
- 侧面/3/4 转头时，发片不穿脸、不出现锯齿状漏光。

做法（下一轮实验，不在本轮）：

1. 合并前发片与头顶发壳，重做内发际线；必要时用一条 alpha 遮罩把硬边柔化 2–3px。
2. 鬓角补一小片“耳前碎发”，遮住发片与脸的缝。
3. 用同一镜头、同一表情拍正面/左转 30°/右转 30° 对照，不以正面静帧单独验收。

### P0 · 嘴与默认表情

目标：

- 静止时嘴线在 128px 脸宽裁切下仍可见；嘴角有 2–4px 的自然上扬，不是一条水平短线。
- 默认表情读“平静、愿意听”，不是“担忧”；眉毛内端略抬、外端放松。
- 说话时开口幅度与 `audio` 时钟一致，不出现只动下巴、嘴线不动的假口型。

做法：先调默认 morph（嘴角/下唇/眉内端），不动骨骼；再用真实 TTS 音频对照开口。
需要一张 `base / soft_smile / listen` 三态对照图，避免把“笑”做成永久营业表情。

### P1 · 光影

目标：

- 前发在额头投下一条 3–6% 亮度差的软阴影，边缘不硬切。
- 额头高光面积缩小，额头与脸颊的色温差不超过一个可感知台阶。
- 主光从左前上方来，右侧有轻微冷色轮廓光；不要用全局提亮掩盖层次。

做法：先加一张方向性 hair-shadow 贴图/遮罩，再调 MToon shading shift；SDF 面部阴影留到
轮廓和嘴稳定之后。不要先换 shader。

### P1 · 主舞台构图

目标：

- 说话/思考时，脸部在 1440 页面中至少 90px 宽；静默时可以回到 55–70px 的“在这里”尺寸。
- 脚下有可见地面阴影（本轮已加强 `::before`，但仍很轻）。
- 身体不被输入框硬切；要么收到腰上，要么让输入框浮在身体前而不是切在腿上。

做法：优先做“说话时轻微推近 + 静默回落”的镜头状态，而不是永久放大；这会同时服务
“她在回应”和“她不挡内容”。

## 4. 本轮改动

| 文件 | 改动 | 目的 |
|---|---|---|
| `web/style.css` | `.avatar-stage::before` 地面阴影从 `#7b906127` / 20px 改为 `#4f5f3d38` / 24px + 2px blur | 让角色落地，成本最低的构图修复 |

没有改：VRM 网格、材质、morph、骨骼、默认表情、相机 FOV、Lab 布局。

## 5. 验证

- 修后主舞台截图：`eval/visual-audit-20261017/main-vrm-desktop.png`；阴影在脚下可见但不过重。
- 既有 VRM/动作回归（下一节统一跑）：`npm run test:vrm`、`npm run test:dialogue-gaze`、
  `node web/avatar/test_gaze.js` 等。
- 本轮没有做“发际线已修好”“嘴已可读”的声明；这些仍是目标，不是结果。

## 6. 下一轮的最小实验

1. 复制一份 `seed-daily-lids`，只改前发内缘与鬓角，保留蒙皮/骨骼；同一镜头拍三角度对照。
2. 只改默认 morph（嘴角 + 眉内端），拍 `base / soft_smile / listen` 三态；不做全身动作。
3. 只加 hair-shadow 贴图/遮罩，拍有/无阴影对照；用像素亮度差验证 3–6%。
4. 三项都通过后，再决定是否做主舞台“说话推近”；不要一次性把资产、shader、镜头全换掉。
