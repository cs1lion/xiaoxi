# 使用说明（v1.0-daily 交付）

给「自己日常真用」这一档写的开机与上手说明。不是给第三方分发的安装指南。

## 开机

```bash
# 在仓库根目录
.\.venv\Scripts\python.exe -m uvicorn server.app:app --host 127.0.0.1 --port 8000
```

浏览器打开 <http://127.0.0.1:8000>（2026-10-25 分家后 `/` 是像素世界；旧聊天页在 <http://127.0.0.1:8000/chat>）。没有 API Key 时自动进入 Mock 模式，全链路可走通（台词是固定的）。

**升级后必须重启服务。** 长期不重启的进程会漂移出不可服务状态（dogfood 实测：10-21 启动的进程上
`/api/memories` 持续 500，当前代码重启后正常）。

**解释器与依赖**：用仓库 `.venv`（本文命令即此）。不要用 anaconda3 的 python 起服务，它的 NumPy 2.x 与编译版
scipy 冲突，`import server.app` 直接 ImportError（2026-10-25 实测）。新建 `.venv` 后先 `uv sync`，
语音栈（faster-whisper / edge-tts / ctranslate2）按 `uv.lock` 安装，缺了实时语音不可用。

## 日常怎么用

| 想做的事 | 怎么操作 |
|---|---|
| 聊天 | 按住左下角麦克风说话，**松开**发送；或直接打字 |
| 连续说多句 | **一句一按**。按住超过 30 秒会被上限切断，且不会自动续录 |
| 让她干活 | 说「帮我……」类委托，例如「帮我安排一个沙盒打样，生成并校验一个小文件」 |
| 确认委托 | **在卡片上点确认按钮**——语音说「确认」目前不算确认（安全设计，见已知边界） |
| 看她在忙什么 | 工作台抽屉 → ops 视图（任务状态、步骤、验收报告、在场状态） |
| 管理记忆 | 记忆侧栏：每条可见来源与时间；可停用（软停用，检索不再注入，可随时恢复） |
| 看世界 | <http://127.0.0.1:8000>（分家后主界面就是世界；<http://127.0.0.1:8000/world> 是静态挂载点） |
| 断线了 | 什么都不用做：自动重连并接续同一个会话（对话线不断） |

## 已知边界

- **首字延迟**：级联管线，Mock 口径 p50 约 95ms、真实模型另计；不追求 500ms。
- **委托入口**：#40 已修，路由不再挂在「帮我」前缀上，ASR 掉词也能识别。若她回「这单我没派出去——接单台词库是空的」，那是没路由到工具路径或样本池空，不是没权限；换个完整句式再试。
- **语音确认未支持**：不可逆操作必须在卡片上点击确认。
- **其他 Worker 仍是人工确认（HITL）**：只有沙盒打样工是真执行。
- **pixel-world 是只读投影**：世界不回写、无外部 Agent transport、无 LLM 生成。世界引擎 2026-10-25 已迁往独立仓 [pixel-world-engine](https://github.com/cs1lion/pixel-world-engine)，本仓 `pixel-world/` 为冻结态不再演进；愿景与八子票账目见 issue #54。
- **真跑演练会让路**：容错演练与 e2e 在常驻服务持有台账时按设计 SKIP；要真跑先停服务。

## 出错时看哪里

- 服务日志：`data/main-server.stderr.log`（按本文方式启动时）
- 全量门禁：`.\.venv\Scripts\python.exe scripts\run_gates.py`（`--allow-skip` 接受环境性跳过）
- 延迟基线：`docs/LATENCY_BASELINE.md`（附复跑命令）
- dogfood 记录：`docs/DOGFOOD_REPORT_20261024.md`
