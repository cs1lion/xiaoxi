# 全双工实验版：软让话、回声参照与句内续播

本轮在连续对话第一版上实现可测试的全双工交互层，不宣称语义附和识别、神经网络AEC或真实设备声学验收完成。真实ASR仍在收句后运行，未变为端到端流式语音模型。

后续[非理想声学压力测试](DUPLEX_STRESS_RESULTS.md)已暴露多路径混响、持续噪声误抢话及弱近端漏检，不能将此前理想测试通过解释为外放可用保证。

## 使用

“声音与形象”中新增抢话策略：

| 策略 | 初步让话 | 取消旧轮所需累计近端语音 |
|---|---|---|
| 耳机 · 平衡（默认） | 120ms后压低至22%音量 | 420ms |
| 外放 · 保守 | 120ms后压低音量 | 600ms |
| 快速打断 | 120ms后压低音量 | 300ms |
| 播放时仅按键打断 | 不自动压低 | 只接受按钮/键盘接管，播完后仍连续收句 |

这些是输入帧时间阈值，不是测得的端到端延迟。候选阶段不上传、不创建新轮、不执行操作，回复继续低音量播放。安静180ms后恢复音量；短于180ms的音节空隙保留累计，但语音占比至少60%，候选最长2秒。短音得到宽容并不意味着系统理解它是“嗯/对”；短促“停”也可能被忽略，请使用停止按钮或快速模式。

确认抢话时取消旧轮，发送260ms预录（250ms按20ms完整帧向上取整）与整个候选段，继续正常900ms停顿收句。播放尾部保护260ms；尾部已起的候选会延续到提交/恢复/上限，不丢句首。录音限长后的安静要求不会因播放启动而消失。

## 音频路径

- AudioWorklet优先：麦克风与实际播放Gain输出作为两路输入，在音频线程混成单声道，同步约20ms块传回主线程。
- 采集器输出恒为零，不把麦克风送回扬声器。实际播放仍走原音频图。
- Worklet加载/建图失败回退1024样本ScriptProcessor；无双路能力则明确显示无播放参照。
- 采集取消会丢弃尚未发送的不足20ms尾帧，阻止迟到回调；因此手动松开最多可能损失一个采集块，不宣称强制音素对齐。
- 浏览器AEC/noiseSuppression仍为主要声学消除。新增EchoGuard只是保守的回声判据，不是替代AEC的滤波器。

## 回声防护

以2kHz降采样、80ms窗口，在0–200ms延迟范围搜索归一相关及线性投影残差。只有高相关且残差很低，当前帧也符合时，才当作回声；双讲、无参考、参考失配不能一律屏蔽。活动录音中被判为回声的帧替换为等长静音，保留计时和端点，不把房间尾音延长成新发言。

限制：非线性扬声器失真、混响、高频信息、近端复述相同内容、AEC处理后的参照失配都可能造成漏检或误抑制。合成线性回声测试通过不等于真实外放可放心常驻；建议从耳机模式开始。

## 被打断句续播

“续播被打断句”只保留当前已解码句的剩余音频和实际播放偏移。新轮结束后可点击，只本地播放，不发新任务，不重放工具，不恢复尚未生成的后续句。最多保留一个AudioBuffer，90秒自动释放；离开/断线清空。不推断哪些字一定已听到，不把部分句子重新写入长期记忆。续播不重新按整句文本驱动口型，避免错误字幕定位。

## 本地观测

2026-10-13 新增[可显式开始的本地语音基线试验](VOICE_BASELINE.md)，首轮环境按用户选择为电脑外放。覆盖真实链路上的能量起点/末端、提交、ASR、解码、播放及停止调用，按固定环境分组，导出不含音频或文字。真实外放及声学时延尚未采集，不能用离线测试填成绩。

偏好区显示采集路径、有无播放参照、候选次数、抢话次数和回声帧数。提交至浏览器开始播放的p50/p95保留最近50次；不包括用户末字至收句的900ms等待，也不等于声卡真实出声延迟。指标只在页面内存，可清空；不保存或上传原始采样作诊断。

## 自动化验证

- `npm run test:voice`：原有VAD/轮次/播放队列，以及双工策略、回声合成、采集器生命周期、续播/指标。
- `npm run test:voice:browser`：真实页面+模拟设备/WS，验证短声压低恢复、持续抢话、策略切换、续播不发任务及旧13组回归。
- `npm run test:voice:worklet`：真实Chromium AudioWorklet及双路振荡器音源，验证双路960样本对齐、音频时钟递增、停止后无迟到块。为了绕过Playwright无法拦截音频线程模块fetch的问题，通过Blob加载同一源文件，不验证部署URL/CSP。
- `.venv\Scripts\python.exe scripts/test_voice_turns.py`：沿用25项服务端轮次测试。

本轮模块44项通过，页面15组检查通过，真实浏览器Worklet合成图验证通过。实际麦克风、扬声器、云模型往返延迟未测。

## 真机调校顺序

1. 耳机安静环境：连续说、短声附和、句中思考停顿、快慢语速、播放即将结束时抢话。
2. 外放低音量，再逐步提高：只播放不说话5分钟，记误抢话次数；再双讲，记录漏检。
3. 风扇/键盘/背景人声：记录候选与提交，不把检测背景人声当成说话人识别成功。
4. 说短促“停”对比持续“等一下我改一下”，验证快速/平衡/保守取舍。
5. 切策略、手动接管、拒绝权限、关闭监听、切后台、断线，检查麦克风与音量恢复。
6. 用外部录音或设备环回测用户开口到实际压低/停播、用户停嘴到首声p50/p95。当前页面指标只能辅助定位链路。

下一阶段应基于这些数据决定是否引入神经VAD/专业AEC、实时ASR意图探测及分句已播放回执；不要仅因功能存在就开放默认外放常驻。
