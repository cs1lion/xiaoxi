# 日常角色的肩部与上身配合

这一阶段让胸部和右肩轻微配合现有抬手、表达和收回包络。沿用原来的语义动作安排、局部肩肘腕姿势和手指松弛，模型与蒙皮不变。实验页的“肩部与上身配合”默认开启，可在同一动作下关闭作对照。

## 骨架与叠加

Daily 的 `chest`、`leftShoulder`、`rightShoulder` 均可用；`upperChest` 缺失。本轮只驱动胸部和右肩。肩部的 normalized 父级为胸部，模型面向 +Z，角色右侧位于 −X。审计依据保存在 `eval/avatar/body-coordination/audit.json`。

胸部 +X 是轻微前倾，−Y 是向右手侧转动；右肩 +Y 前送、−Z 抬起。胸部对外套有直接权重，右肩对肩部与袖子有直接权重，因此需要看实际服装变形。

`spine` 继续承接原来的 BodyAngle/BodyLean 参数，头颈继续使用原来的角度映射。本轮驱动的两个节点没有独立的 idle 映射，渲染器捕获其绑定四元数，在实际 normalized 局部姿态上平滑接近 `rest * offset`；不会把偏移反复累加。上身父级改变后，手腕、手指和脸的世界位置会轻微变化，局部手臂姿态不变。

肩胸层在 humanoid 同步和眼睛 LookAt 计算之前应用。眼睛方向继续根据最终头部世界旋转合成，避免使用上一帧的上身姿态。现有 VRM `mapParams` 没有将 `ParamBreath` 映射到躯干，本轮没有增加呼吸驱动。

## 姿态与恢复

`web/avatar/render/body-poses.js` 的满包络、满强度 XYZ 偏移为弧度：

| 动作 | 胸部 | 右肩 |
| --- | --- | --- |
| 招呼 | .010 / −.006 / 0 | 0 / .010 / −.030 |
| 否定 | .005 / −.008 / 0 | 0 / .006 / −.020 |
| 自我强调 | .004 / −.004 / 0 | 0 / .004 / −.012 |
| 摊掌 | .012 / −.008 / 0 | 0 / .010 / −.025 |

最大合成角约为胸部 .83°、右肩 1.81°；自我强调最小，避免扩大靠近胸口的手势。姿态乘以原 `weight` 与 `min(1, strength/.15) * (.65 + .35*strength)`，减少动态再乘 .4。未知动作、休息、零强度和取消帧都返回零偏移，不增加按 phase 摇身的周期。

实际关节使用 `1-exp(-10*safeDelta(dt))` 插值，渲染帧时间上限 .05 秒。打断时目标立即回到原绑定姿态，恢复由渲染时间推进，不依赖音频时钟。零帧时间和开关切换保留当前姿态，开关不重置手臂的过渡控制器。

接口为 `setBodyCoordination(enabled)` 与 `getBodyCoordination()`，后者返回 `{available, enabled}`。仅精确 Daily 模型适配；缺少部分节点时跳过，其他模型不写肩胸。眼睛校准进入时将这两个节点固定到原姿态，退出时恢复开关和进入前的实际关节旋转。

## 验证

单元命令：

```powershell
node --experimental-default-type=module --test web/avatar/test_body_poses.js web/avatar/test_body_rig.js web/avatar/test_calibration.js web/avatar/test_finger_rig.js web/avatar/test_gesture_paths.js
```

39 项检查通过，包括低强度连续性、减少动态、取消恢复、绑定合成、零帧时间切换、缺失模型、校准固定/恢复，以及生产 draw 中的基础头颈/脊柱映射和最终头部坐标下的眼睛方向。

真实模型浏览器检查脚本为 `scripts/test-body-coordination-browser.mjs`。同一模型、固定镜头与统一捕获条件下记录局部手臂和指节、肩胸与世界手腕/指尖/头部姿态，检查衣领、袖肩以及手与脸、胸部的间距。证据保存在 `eval/avatar/body-coordination/`。

正式浏览器检查通过 5 组，随后顺序通过动作衔接回归 7 组、语音表演回归 9 组。浏览器错误、麦克风访问、真实模型/语音服务调用及 API 写入均为零。报告分别为本目录证据的 `after/report.json`、`eval/avatar/pose-transitions/results.json` 和 `eval/avatar/speech-performance/results.json`。

14 种固定姿态使用一致的前后输入；正面镜头为 600×720，±25° 斜视统一为 840×720、镜头后退 15%，并确认实际引用的活动手部顶点全部在斜视画面内。动态序列按 60 Hz 推进生产 draw 与骨架更新，共 470 个控制采样点（自我强调→摊掌→休息 289，招呼→打断 181）；实际图像按 20 fps 捕获，共 158 张。预热和未捕获帧跳过 GPU 提交，截图前刷新实际蒙皮包围范围。该验证不代表完整场景持续以 60 fps 光栅化。

前后局部手臂、手指、头颈和脊柱姿态保持，眼睛相对最终头部的方向保持；肩胸父级造成的最大实测关节世界位移为静态 .00977 米、动态 .00961 米，实际蒙皮指尖顶点位移最大 .01028 米。低强度、减少动态、零帧时间开关、关闭恢复和原生音频时钟冻结后的打断恢复均通过。源文件、模型指纹和实际引用的几何记录已核对，模型未改动；详见 `metrics.json`、`after/report.json`。

独立目视复核覆盖 6 对正式静态图和 8 对动态抽样，未见新增明显的领口、肩袖裂缝或自我强调手势穿入可见胸口衣料。变化较小，招呼的肩部抬升更容易观察；既有低模袖口和肘部硬褶仍在。正面动态有部分中间手部伸展同时超出前后画面边缘，不能据这些图确认画外手部；正式斜视静态检查使用已放宽且全手入镜的画面。范围与限制记录于 `visual-review.json`。

实际渲染对照为 `wave-interrupt-comparison.gif`、`self-palm-rest-comparison.gif`，同源固定肩部裁剪为 `wave-shoulder-comparison.png`；`comparison.html` 提供播放与逐帧查看。两边保持相同模型、动作和机位，裁剪不单独对齐或放大动作。

本轮仍使用四种已设计好的动作配合，没有新增 IK、抓握、衣物或手部碰撞求解。有限机位、几何距离和有限骨骼数值不能证明所有动作组合都无穿插，也不能证明整套动作已经自然。
