## 7. 仍然不能用/不能声称的

- **生产隔离未解决**：Claude/DSH/WorkBuddy 都带 `danger-full-access` 或等价绕过；虽然工作目录
  是独立 commission 树，但没有 OS 级沙箱。接不可信任务前必须先定 WSL / cua sandbox / 专用用户。
- **只跑了一轮同题**：3 个 Worker 各 1 次 PASS，是 R2，不是稳定性（R3）。没有 10 题 × 多轮的
  通过率与成本曲线。
- **网关只翻译文本与工具**：图片、thinking、prompt caching、Anthropic beta 头不翻译；输出上限 16k。
- **成本显示不可信**：Claude Code 按 `claude-opus-5-5` 估算美元，实际上游是 StepFun；不要拿
  界面上的 cost 当账单。
- **真实麦克风/扬声器未验收**：语音链路只有离线/受控浏览器回归，没有真机听感与回声测试。
- **UI 方向 B 只是原型**：`web/design-preview/live-20261017/` 未进生产；生产只做了可读性与短屏修复。
- **Codex 未进默认池**：`enabled:false`，等隔离决策。
