# 阿栖原创角色设计 / Character Study 01

## 状态与交付边界

本文件为原创概念设定板的制作规格。第一张 AQI Character Study 01 已通过会话 image_gen 工具实际生成，工具输出为可见图像，包含半身主视觉、正背全身参考、六种表情和配色。尚未获得可用于复制到项目静态资源的文件路径；不能将此规格文档或概念图作为原创 VRM 已完成的证据。概念图是视觉方向稿，不是可加载 VRM，不是严格建模三视图，不代表现有官方测试模型已变为原创角色。尚待制作原创网格、贴图、骨骼、表情以及导出验证。

不得通过给 pixiv 示例换色、加配件就把它标成原创阿栖。现有实验室继续保留示例来源和许可说明。生成图中服装细节、头发长度或左右位置可能有视图间误差，生产时以本文的统一规格和后续正交稿为准。

## 参考方法与证据

- VRM MToon 标准：https://github.com/vrm-c/vrm-specification/tree/master/specification/VRMC_materials_mtoon-1.0 。生产方向为卡通材质，而非 PBR 皮肤写实。
- three-vrm：https://github.com/pixiv/three-vrm 。现有网页使用该运行时；视觉设计必须在浏览器固定镜头、实时骨骼和表情条件下成立。

### 审美参照（设计判断，非公众排名调查）

借鉴成熟二次元游戏角色常用的清晰轮廓、主辅色组织、上半身识别点；参考《原神》《崩坏：星穹铁道》的整体角色设计完成度，但不复制某个角色的五官、服装、徽记或组合特征。日常陪聊不需要战斗角色密集的装备、束带和材质种类。

网页搜索服务当前返回鉴权错误，因此不宣称已搜集到“公认优秀”的投票排名、统计或实时舆论。本设计以一手技术资料和明确标注的审美判断为依据。

## 设计目标

成年女性角色，气质聪明、平等、略有调侃感。适合长时间中文语音聊天，不是客服招牌笑，也不靠性感服装建立吸引力。

优先级：脸部可读性 > 半身轮廓 > 角色辨识度 > 全身服装细节。

## 统一生产规格

- 正常成年体型，避免幼态身体比例；不做写实皮肤毛孔。
- 发型：墨蓝及肩短发，略不对称分缝，主体以可辨识大束组织。前额留出眉毛活动空间，发尾不得持续遮挡嘴角。概念稿若出现偏长发束，建模时收束至肩线附近。
- 眼睛：灰青虹膜，少量暖色内圈；高光克制，不用高频闪动或过大的瞳孔缩放代替情绪。
- 标志：角色自身左侧（正面观察者右侧）的杏橙抽象栖鸟发夹，所有视图位置一致；使用原创简单剪影，不采用既有 IP 图标。
- 服装：奶油白短外套、深墨蓝翻领和袖口、简洁深色内搭、炭灰长裤。上衣装饰只保留单侧小口袋与细拉链拉片，避免小字和碎花。
- 材质：衣料为低光泽；金属件限制在拉链和发夹小面积，不使用大范围镜面高光。
- 非目标：机械义体、武器、制服徽章、品牌 Logo、复杂裙摆、密集首饰。

## 表情规格

| 状态 | 主要信号 | 避免 |
| --- | --- | --- |
| 自然 | 眼睑放松、口角近中性、稳定注视 | 永久露齿笑 |
| 调侃 | 单侧眉略抬、小幅不对称笑、轻侧头 | 整张脸挤成夸张笑脸 |
| 得意 | 小幅抬下巴、含蓄笑眼 | 闭眼导致持续看不到视线 |
| 认真 | 眉形收拢、视线稳定、嘴回中性 | 直接套愤怒脸 |
| 收敛 | 眉内侧轻抬、短暂下看、减弱笑意 | 悲伤哭脸 |
| 轻微不服 | 眉略压、嘴角小幅偏移、短暂侧看 | 敌意怒视 |
| 变小气 | 视线回避、唇线轻收、幅度更小 | 夸张噘嘴常驻 |

先交付独立 blinkLeft/right、aa/ih/ou/ee/oh、happy/sad/angry，再加 teasing/proud/serious/reserved 等自定义表情。自定义表情不能覆盖嘴型和眨眼；嘴型与笑意要做组合测试。眉毛和眼睑必须是实际可驱动形变，而不是仅在概念图里存在。

## VRM / MToon 制作要求

- 导出自包含 VRM 1.0；纹理、骨骼、表情都包含在模型中，不依赖第三方纹理 URL。
- 与现有 normalized humanoid 驱动兼容，检查 head/neck/spine、左右眼、手臂。
- 头发仅对较大独立束添加 SpringBone；碰撞体覆盖头颈肩部，不做每根碎发独立物理。
- 正面与左右约 25 度内转头为第一验收范围；嘴、睫毛和眉毛在该范围不能穿插消失。
- MToon 以大块明暗和少量描边组织体积。不要追求随机灯光下全部自动漂亮；优先固定聊天镜头的稳定效果。
- 建议先以 2K 主贴图、有限材质槽做资产预算，实际包体、draw call、GPU 帧耗时应导出后实测，不承诺理论 FPS。
- 原始建模工程、贴图源文件和许可证应随成品保存，以便长期改表情、衣服和运行时。

## 验收清单

- [ ] 原创正交前／侧／后稿统一，发夹和口袋左右一致。
- [ ] 320px 高半身视口仍能看清表情，眉毛不被刘海遮挡。
- [ ] 深浅背景都能辨认头发边界和肩线。
- [ ] 待机 60 秒没有持续摇摆、头发抖动和周期性夸张点头。
- [ ] 七种情绪可辨，不靠文字标签才能区分。
- [ ] “爸爸妈妈”“你好”“我不同意”口型闭合与张开正常。
- [ ] 微笑加眨眼加说话不会破面；打断后及时闭嘴。
- [ ] 三个角度无睫毛、发束、领口穿插，眼睛无异常透视。
- [ ] 实验室导入、SVG 回退、聊天页和移动视口通过现有回归。
- [ ] 最终角色网页使用、商用、修改和分发权明确，移除示例模型冒充成品的可能。
