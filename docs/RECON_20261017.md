## 3. 网关 `15721` 的真实能力边界

```
GET  /v1/models   200，3 个模型：step-3.7-flash / step-5-preview / ccs-agnes/agnes-3.0-flash
GET  /            404
POST /v1/messages 400 {"error":{"message":"配置错误: Claude Provider 缺少 base_url 配置","type":"proxy_error"}}
```

- Codex 的 `config.toml` 用 `wire_api = "responses"`，`experimental_bearer_token = "PROXY_MANAGED"`，
  `requires_openai_auth = false`。这条链路是通的。
- Claude Code 的 `settings.json`：
  `ANTHROPIC_BASE_URL=http://127.0.0.1:15721`，`ANTHROPIC_AUTH_TOKEN=PROXY_MANAGED`。
  请求能到网关，但网关没有 Anthropic Provider 的 `base_url`，所以 400。
- 15721 只做“某个 Provider 的本地出口”，没有 Magpie 那种多协议翻译、路由组、配额/成本台账、
  Agent 配置重写。它也不是为多个 Agent 同时服务设计的。
- 结论：**Claude Code 在本轮不是可用 Worker**；不能把“已安装”“配置指过去了”写成“可当 worker”。

观察：

1. **发际线**：前发是一块带硬折线的三角片，额头处有明显接缝；左侧鬓角与脸之间有一道缝隙。
   这是当前最像“未完成资产”的信号。
2. **嘴与表情**：静止时嘴几乎不可见，只有很淡的一小段；配上略平直的粗眉，默认读起来偏“平淡/担忧”，
   不像陪伴角色。眼睛很大、高光很亮，情绪主要靠眼睛承担。
3. **光影**：额头有一块偏白的高光区，脸颊暖色；头发在额头没有投影，前后景像贴纸。
   背景是深蓝渐变，人物边缘有轮廓光，但脸部本身层次少。
4. **构图**：主舞台 240×340，头高约 80px，脸宽约 55px；在 1440 页面里读不清表情。
   没有地面阴影，身体被输入框截断，像悬浮贴片。
