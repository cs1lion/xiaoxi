# 及肩短发＋日常短外套 / 2026-10-13

这一版是实际可加载的 VRM 造型改版。基于 Seed-san 保留脸部、骨架与既有动作系统，重建偏分及肩发、针织内搭、奶油色短外套与炭灰裤装；移除机械臂、背包、装备腕带、制服图案和手套视觉。没有依靠徽饰识别角色，也没有增加夸张胸部或暴露剪裁。

预览：<http://127.0.0.1:8000/static/avatar_lab.html?model=daily>；聊天：<http://127.0.0.1:8000/?avatar=seed-daily>。

## 可编辑资产

- `web/models/seed-daily.vrm`：自包含衍生资产；原始 `seed-san.vrm` 未改动。
- `scripts/build_seed_daily.py`：网格、材质与权重的可编辑生成源码，运行需要 Python、numpy 和 Pillow。scipy 可选，缺失或版本不兼容时使用 numpy 分批转移权重。
- `web/models/seed-daily-source/`：原创针织纹理与生成清单。
- `web/models/SEED_DAILY_LICENSE.md`：来源、原作者 VirtualCast, Inc.、VRM Public License 1.0 与改动说明。它是衍生角色造型，不标为原创阿栖模型。

## 实际修改

新服装按原始逆绑定矩阵的 A pose 建模并转移身体权重；没有按骨骼静态 T pose 猜位置。袖子保留上臂、前臂与扭转骨骼影响，袖口排除手指影响，领口固定于胸部，裤腿排除另一侧腿的影响。服装覆盖的原身体表面从渲染三角形中剔除，保留脖颈、双手与脚，避免腹部或肩部皮肤穿出。头发沿头骨运动，本轮没有新增发束物理。

## 验证结果

结构审核保留 51 个骨骼映射、全部原始绑定矩阵、43 个原脸部 morph 和表情绑定。活动网格没有机械装备材质引用；索引、法线与归一化权重通过检查。袖口手指、裤腿跨侧和领口手臂的非预期权重已经清除。

浏览器回归通过四个手势、口型、眨眼、实时打断、回到休息姿势、减少动态、SVG 切换、重新加载、加载失败保留当前形象、聊天入口和移动视口。无页面异常。测试设备为 Chromium / SwiftShader，不据此宣称实际设备帧率。

视觉检查覆盖正面、左右约 25° 镜头、左右转头、招呼、摊手、否定、自我强调及打断后姿态。修正了腹部穿出、肩部尖角、反向法线和袖口衣料穿插；最终截图所覆盖姿态未见明显的新穿插。该结果不能覆盖未来新增动作的所有姿态。

验证脚本：`python scripts/validate_seed_daily.py web/models/seed-daily.vrm`、`node scripts/test-seed-daily-browser.mjs`。结果、模型 SHA256、审核报告与截图保存在 `eval/avatar/daily-*`。
