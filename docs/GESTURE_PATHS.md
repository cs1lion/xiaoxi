# 日常手势的抬起与收回路线

本轮只调整日常角色四种手势的运动路线：自然姿态 → 身前屈肘准备 → 已校准的表达姿势，收回按同一路线反向采样。四种表达姿势、台词意图、锚点、音频时钟和动作窗口保持原值。

后续[手指松弛](FINGER_RELAXATION.md)在同一动作包络下调整四指，本文保留手臂路线阶段的证据。

## 路线的依据

上一轮校准了目标姿势，但运动途中仍把肩、肘、腕的所有角度乘以相同包络。前臂轴向转动与屈肘混在一起，手尚未抬起来就开始大幅翻掌。

这次对完整和克制强度分别编写准备姿势：上臂保持靠近身体，肘部先弯到身前，手腕接近中立、手指顺着前臂方向。后半段才接近原有目标和完整转掌。招呼与否定的摆腕也在后半段逐渐进入。

准备姿势通过 `scripts/calibrate-gesture-poses.mjs --paths` 在实际骨架上离线转换为相对休息姿态的 XYZ 角度；方向、测量和截图位于 `eval/avatar/gesture-path-authoring/`。招呼与否定的前臂选择与最终姿势相邻的等价 Euler 分支，避免角度表达跨分支引入额外转圈。运行时没有新增 IK。

`web/avatar/render/gesture-poses.js` 在休息、准备和终点之间使用单调 Hermite 插值，中点位于包络 .5。实际中点是原半程目标与离线准备姿势的混合，正常模式准备量为 .6，减少动态时为 .3；减少动态的最终角度仍乘以原 .4 系数。这样保留分步准备，也限制额外转动路线。

曲线端点采用单侧割线斜率，中点同向轴使用共享调和斜率、反向轴使用零斜率。起止的时间缓动由导演既有 smoothstep 包络负责，避免在包络之上再次施加强端点缓动、把运动挤到中段。各轴在每段两个角度之间采样，不作过冲，但这不等于证明实际关节速度全程连续。

强度仍在克制和完整姿势之间选择，低强度激活沿用原系数。零包络准确回到休息，满包络与原校准目标完全相同，过渡层用于估计角度差的 reference 目标也保持原值。通用模型继续使用原采样方式。

## 实验页对照

打开 `http://127.0.0.1:8000/static/avatar_lab.html?model=daily&preview=gestures`，在“02 / 性格与动作”中重复播放同一手势。默认打开“分步抬手与收回”；关闭后恢复上一轮校准姿势使用的同步抬手与转掌路线。另一个“使用校准后的日常手势”开关仍负责校准姿势和旧通用姿势之间的对照。

渲染器提供 `setGesturePaths(enabled)` 和 `getGesturePaths()`，后者返回 `{available, enabled}`。路线仅在当前模型适配且启用日常校准时可用。切换模式清除旧过渡快照，保留实际关节姿态和导演进度；切换模型沿用实验页的取消流程。眼睛校准进入/退出时保存和恢复该开关。

## 动态验证与边界

浏览器脚本 `scripts/test-gesture-paths-browser.mjs` 使用真实 daily VRM、生产动作导演和渲染器。受控音频时钟按 60 Hz 推进，记录每帧实际肩肘腕四元数、手腕位置、屈肘角度和掌面法线，并在检查点投影手部蒙皮顶点。覆盖四动作完整/.4 强度、减少动态，以及自我强调和摊掌的左右 25° 视图。

基线源码与动态数据位于 `eval/avatar/gesture-paths/before/`；新数据位于 `after/`。`comparison.html` 提供同一镜头的自我强调/摊掌动态并排对照，可暂停和拖动。不能仅凭静态准备姿势或有限变换断言自然度提升：还要比较实际抬起/收回的速度、掌心翻转与视觉停顿。

第一轮完整准备量与额外端点缓动的试验保存在 `round1/`。实际测量显示部分动作的峰值转动明显增大，因此调整为上述准备量和端点斜率。最终路线的额外转掌仍有速度代价，不能描述为四种动作在所有强度下一律更慢。

相关单元测试为 `web/avatar/test_gesture_paths.js`；浏览器还检查关闭路线能恢复原序列，准备阶段打断保持瞬时实际姿势，以及原生音频时钟挂起后仍能收回。语音锚点与动作衔接的回归分别见[台词与动作意图](SPEECH_PERFORMANCE.md)和[当前姿态衔接](POSE_TRANSITIONS.md)。

最终路径单元测试 11 项、原姿势 12 项、眼睛校准 11 项通过；校准退出恢复此前的路线开关。另通过导演/停止、姿态过渡和 VRM 映射回归。路径测试还在实际导演与过渡器中模拟四动作、四强度和四时长共 64 个减少动态组合，限制相对旧版的峰值骨骼步长增幅。

最终浏览器通过 6 组检查、16 条真实渲染序列，四种动作实际峰值与基线的最大关节角度差约为 `2.8e-7 rad`。关闭路线的四条完整序列与基线一致；四动作准备阶段打断和模式切换不产生瞬时跳位，原生音频时钟挂起后仍能恢复到休息。所检完整表达姿态中的手部蒙皮顶点均在镜头内，检查没有浏览器异常、麦克风调用或 API 写入。

最终源码下的衔接浏览器回归 7 组、台词语音同步浏览器回归 9 组通过；结果分别保存在 `eval/avatar/pose-transitions/results.json` 与 `eval/avatar/speech-performance/results.json`。路径最终源码快照的 SHA256 与当前渲染器和姿势文件一致。

以下为完整强度、正面、60 Hz 的实际测量。单帧角度是所有手臂关节中的最大值，手腕速度按模型世界坐标与采样时间计算；它们是相对诊断指标，不是人体动作的运动学验收。

| 动作 | 最大关节步长，旧 → 新（rad/帧） | 手腕峰值速度，旧 → 新（模型坐标/秒） |
| --- | --- | --- |
| 招呼 | .177 → .168 | 4.221 → 3.538 |
| 否定 | .188 → .177 | 3.108 → 2.598 |
| 自我强调 | .235 → .207 | 3.292 → 2.829 |
| 摊掌 | .242 → .260 | 3.225 → 2.226 |

摊掌的手腕移动变缓，但局部转掌的峰值仍略高；减少动态下招呼/否定最大关节步长分别增加约 12%/7%，自我强调/摊掌则略降。16 条序列均在预先设定的相对基线 25% 增幅检查内。该界限是防止本轮大幅加速的回归约束，不能单独证明自然度。

前后动态见 `self-comparison.gif`、`palm-comparison.gif` 和 `comparison.html`，时序联系图为 `self-path-contact.png`、`palm-path-contact.png`，详细速度阶段见 `path-speed-review.json`。保存的正面样本中，自我强调收回的横向摊掌扫过感减弱，摊掌降低时保留开放掌面更久；抬起的改善较小，末段转掌仍偏快。模型 SHA256 保持 `f516bfdb7b00c87fcdbffb98c012842ca727ae835638716e704adae09271955a`。

这一步保留模型文件、服装网格和蒙皮。没有手指弯曲、衣服碰撞求解或躯干协同。现有袖口内缘、肘部硬褶皱与平直手指仍会影响自然感；有限镜头检查不能覆盖所有台词长度、动作组合和设备帧率。
