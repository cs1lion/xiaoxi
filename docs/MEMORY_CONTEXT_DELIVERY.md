# 组合记忆第一增量：完整传递与有效召回

2026-10-13。落实[记忆组合设计](MEMORY_COMPOSITION_DESIGN.md)的第一增量：统一普通聊天与行动助手的记忆表达，修正候选集合及索引失效。没有新增项目 schema、向量接口或图数据库。

## 当前行为

普通聊天与“一起做”现在使用同一个纯转换函数，传递记忆主体、来源说明、证据状态和原消息引用，以及合格偏好的对象、程度、时间范围、原话日期和未确认延续提示。

| 情况 | 现在如何交给模型 |
| --- | --- |
| 长期最爱绿茶，最近也喜欢红茶 | 两条保留不同程度和原话时间；默认聊天 600 字符内可以同时容纳，一起做保留相同核心 |
| 早年的“现在喜欢乌龙茶” | 保留当年原话日期，标明未确认延续；不使用写入时间补日期，也不编造过期日 |
| 用户手动纠正一条偏好 | 人工保存来源明确，旧结构化偏好/原话关联清除；另一个并存成员仍可使用 |
| 旧记录、推测或角色自身记录 | 保留对应来源与不确定性；不冒称用户逐字说过，不授予行动权限 |
| 非法来源/偏好元数据、缺失或异常日期 | 不升级证据或偏好权限，缺日期保持未知；单条异常不会把全部行动上下文变为不可用 |
| 一条内容过长、含敏感凭据或超出上下文预算 | 整条省略，避免截去末尾否定或时间限定后改变含义；不扩大已有预算 |

共享记录默认只传证据状态和合格的消息 ID，不在每轮复制完整原话、会话 ID 或内部成员/水位字段。消息关联证明可追溯，仍不能单独证明模型概括的语义准确。

第一增量时，行动助手基础 context 使用 12000 紧凑 JSON 字符预算、最多六条记忆及每条 320 字的完整内容准入；普通聊天使用包含边界说明在内的 600 字符记忆预算。2026-10-14 已新增[最终动态上下文收口](CONTEXT_BUDGET_AND_USAGE.md)，纳入随后叠加的事项/活动资料与行为策略，统一为 12000 字符；原有记忆分域准入仍保留。上限覆盖补充资料，不覆盖静态提示和完整执行核心，也不是 token 或费用上限。

人工保存可以作为用户维护内容使用，不要求每轮重新确认；缺原话的旧记录仍提示核对。开关关闭时仍不访问记忆检索和来源存储。

## 候选与索引

此前索引读取最近 5000 条 active，实际候选读取最近 5000 条全部状态后再过滤。大量新历史可能挤掉旧有效记录；done 也只有空查询能正常列出，非空文本缺少对应索引。

现在用同一次 SQL 查询读出 active 候选，显式 include_done 时加入 done；索引和排序使用同一份查询时快照。历史和冲突不占候选限额，去掉检索中的隐式 5000 条上限。管理列表的分页上限保持原接口行为。

缓存只依据候选的 ID、key 和 value 内容签名更新。保存聊天消息、更新使用次数或改变纯排序元数据不再触发 TF-IDF 重建；排序仍读取本次记录的来源、权重和时间。另一数据库连接修改文本、删除或改变候选资格，也会在下一次读取时更新索引。索引构建和查询由同一锁保护。

删除在后续读取观察到变更后生效，已开始的搜索仍有其读取时快照；不能承诺撤回已发送给模型的内容。候选集不再静默截断，但仍会读取和比较全部有效记录，本轮没有长期大规模性能测量，不声称已支持任意规模低延迟。

## 实现与验证

- [presentation.py](../server/memory/presentation.py)：只依赖标准库，调用方注入文本清理器，不读取数据库、配置或调用模型。
- [context.py](../server/assistant/context.py)：行动助手沿用共享核心，再附自身外围字段和确认提示。
- [retriever.py](../server/memory/retriever.py)：普通聊天沿用共享核心；同候选快照检索、文本签名缓存和查询锁。
- [store.py](../server/memory/store.py)：新增有效候选查询，不升级 schema 或修改管理列表协议。

新增有效召回反例使用隔离合成数据：5001 条新历史不能挤掉旧 active；5001 条新 active 后旧相关信息仍可检索；done 的非空查询只在显式包含时命中；消息和使用统计不重建文本索引；排序元数据即时影响结果；另一连接修改与删除可见。

两条路径一致性使用真实临时存储的绿茶/红茶记录，不通过扩大默认预算绕过。手动成员纠正、凭据省略和跨连接删除也分别检查行动上下文。其余接缝使用假模型、合成设备/传输或 ASGI 调用，不代表云模型和真实语音听感。

新[离线重放报告](../eval/research/memory_context_delivery_replay_20261013.json)保留原话时间、来源报告与哈希。它验证当前程序对冻结输出的行为，不是新提示词的真实模型成绩；人工语义评分仍为空。

本轮未迁移真实用户库、追加付费接口调用、采集麦克风或重启生产服务。最新代码尚不以旧服务的可访问性证明已部署。
